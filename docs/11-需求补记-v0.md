## 1. 语音与启动（来自 R15 可用性 + R6）

- **启动必须播报语音后端状态与失败原因**。没声音且无提示＝"失败静默"，Round A P0 一票否决。
- **可选按键提示音**：用于可用性测试的"按键→TTS 起始"延迟锚点；默认关，测试/高级选项可开。
- 默认语音链：Tolk → NVDA 直连 → ZDSR → SAPI5 → 静默+诊断日志；每级失败记录原因（10s 重试）。
- 无日语语音时明确提示"当前用中文音色读日文，不可懂"，不许静默降级。
- 日志必须带时间戳（应用内时延可测）；日志不得含台词、CG 路径、用户名。

## 2. 安装与回滚（来自 R15 + R7 反馈）

- SmartScreen/杀软/解压层级等安装阻断点，必须有写进 README 的自救路径。
- 卸载后 Steam 完整性检查通过、原版可玩＝回滚底线（R15 C06，100% 通过）。
- 安装/卸载都必须显式记账（manifest），不允许"装了但说不清改了哪些文件"。

## 3. 合规（来自 docs/10）

- 首启风险告知页：只处理自有单机游戏；Steam 协议禁止修改/篡改；可能封号；确认后才继续。
- 默认离线单机模式；检测到在线/反作弊即停，并说明原因。
- 不随包 GPL/专有二进制；LGPL 组件附源码地址；NOTICE 与实际组件一致。
- 遥测默认关，开启需单独同意。

## 4. 保护与未知程序（来自 R11 + 用户"万能"要求）

- 分析前门：保护/加壳检测（UPX 可自动；其他壳/商业保护器只检测+人工待办）。
- 生成器流程先读归档/资源（rpa/xp3/Unity 资源），再决定是否碰 exe。
- 绝不 attach/dump 商业保护器、不绕 DRM、不改/不换游戏 exe。
- 未知程序路径：L1 通用捕获（UIA/GDI/DirectWrite/内存/剪贴板）→ L2 OCR 兜底（默认关）→ L3 Ghidra 报告；每层都写清覆盖/未覆盖。
