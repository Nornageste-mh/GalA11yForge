# 0.2.6 计划（草案 v0）

- 起草：2026-11-15
- 当前版本：0.2.5.0（已发布，618 测试全绿）
- 上一版：0.2.4.0（612 测试）

## 1. 本版要解决的三件事

1. **把“字段兜底”的泛化面摸清**：R31 全库只读扫描，回答“本机 10 个 Unity Mono 游戏里，有几个能靠字段兜底读到文本、几个不能”，并据此调整对外话术（不夸大“万能”）。
2. **把“未知程序兜底”最贵的一环降下来**：UIA 事件订阅原型 + A/B 实测（当前 100ms 轮询实测 391–1439ms/轮，太慢）；决定 0.2.6 是否把 ExternalReader 从轮询切到事件优先。
3. **Ren'Py 在 0.2.5 生成物上复验**：补一条“真的出声”的客观证据（loopback），把 Ren'Py 从“部分验证”推进到“有录音证据”。

## 3. 发布门槛（0.2.6）

1. 全量测试全绿（当前基线 618，新增功能另计）；不得低于上一版通过数。
2. 每个“已验证”结论都有可复现证据（命令 + 日志/截图/录音）；未验证项在发布说明里如实列出。
3. `releases/v0.2.6/`：forge.exe + Fingerprints + BepInEx zip + GUI + SHA256SUMS，全部校验通过；发布版冒烟 detect/analyze/plan。
4. 版本号按 0.2.x 叠加（0.2.6.0），不得夸大。
5. 文档同步：README、docs/18 使用指南、docs/12 基线、发行说明 docs/40（或 39 续）、docs/23 收口记录。
6. 给用户发一封中文邮件：本版新东西、已验证/未验证、下一步与待拍板事项。
7. 不引入新的 GPL/专有二进制随包；不扩大“可支持游戏”的对外承诺。

## 4. 明确不做

- 不做 UI 大改（GUI 已够用，等人工验收回执）。
- 不把 KKZ 适配器塞进发布包（设计先行）。
- 不做跨平台（Windows only）。
- 不做自动下载 Ghidra/游戏内容等大依赖（BYO/按需，已定）。
- 不在未获用户授权时碰真实游戏目录做实验（本次事故后的硬纪律）。

## 5. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| UIA 事件在真实应用上抖动/挂起 | 万能层不可用 | 保留轮询兜底；事件放独立线程/进程，硬超时 |
| 全库扫描发现字段兜底只覆盖很少作品 | 对外话术需收缩 | 用数据说话，更新 docs/22 打回预案 |
| Ren'Py loopback 录不到“可辨人声” | 无法宣称“已朗读” | 如实标注未验证，保留日志证据 |
| KKZ 用户不授权 | 0.2.6 少一项 | 不阻塞发布，列为“研究中” |
