# GalA11y Forge 0.2.69.0 发布说明

## 一句话
`verify --speech-log` 现在能统计 Ren'Py 覆盖层的播报行（`[A11y对话]`/`[A11y屏幕]`/`[A11y菜单]`），不再把 Ren'Py 的正常朗读当成「没证据」。

## 为什么做
Ren'Py 走运行时覆盖层，日志长这样：

```text
[A11y对话] +3.577s 这是第一句测试对白。
[A11y屏幕] +9.554s 提示：问题是：你要去哪里？。选项 2 个：1 去公园；2 回家
[A11y屏幕] +9.555s backend=NVDA 提示：问题是：你要去哪里？。选项 2 个：1 去公园；2 回家
```

旧检查器只认 `[Speech]`/`[a11y-speech]`/`[朗读]` 和 `backend=SAPI`，所以 Ren'Py 日志经常被判成「0 有效行」；同一句又会被非 backend 行 + backend 行记两次。

## 改了什么
- 新增 `RenpyChannelRx`：匹配 `[A11y对话|屏幕|菜单] [+1.234s] [backend=XXX] 文本`；
- 新增摘要字段 `RenpyLines`，verify 指标输出 `speechRenpyLines`；
- `backend=` 开头的 Ren'Py 行按回声处理：同句已计过就只记 `EchoLines`，不再虚增有效行；
- 新增单测覆盖三行 Ren'Py 日志（2 有效 + 1 回声）。
