# GalA11y Forge 0.2.31 发布说明

- 版本：`0.2.31.0`
- 日期：2026-11-16
- 发布目录：`releases/v0.2.31/`
- 上一版：`0.2.30.0`（GUI 高级分析复选框被裁切 hotfix）

## 1. 本版做了什么

给 GUI 增加「分析报告」按钮（`report` 命令，Alt+P），让**没有内置适配器的未知引擎**也能在图形界面里走完：

1. 识别引擎（detect）
2. 分析文本，勾「高级分析」走 Ghidra（analyze --advanced）
3. **分析报告（report）** ← 本版新增

报告会写 `reports/<slug>/report.md`、`report.json` 与 `human-todos.md`，内容包含：引擎与置信度、路线（自动/半自动/不支持）、覆盖声明、Ghidra 静态分析摘要、未覆盖项、人工待办（含 Blocking 的“该引擎没有内置适配器，不能自动生成可安装补丁”）。

## 2. 为什么要做

0.2.28 起 CLI 已支持“无适配器也能导出分析报告”，但 GUI 没有入口——而目标用户里有读屏用户，不能要求他们敲命令行。0.2.31 补上这一步，并做了**发布包 GUI 真机验证**。

## 7. 已验证 / 未验证

## 8. 升级建议

从 0.2.30 直接覆盖解压即可；工作区（`%LOCALAPPDATA%\GalA11yForge` 或 `--workspace`）不需要迁移。GUI 与 CLI 都建议一起升级，避免“GUI 老、CLI 新”的命令不匹配。
