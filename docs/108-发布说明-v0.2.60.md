# GalA11y Forge 0.2.60.0 发布说明

## 一句话
计划里只剩「位置 / 音乐时长 / 标题」这类非台词字符串参数时，不再当作正文入口——会照常报 R-106 高风险，安装闸门也会拦。

## 为什么做
32 个子代理体检（research/141）发现：108《Sister Other Paranoia》扫到的是 locationText/音乐时长，111《我与你共度的七日》默认锚到启动器，112《妹控计划》钩子全打在死代码上——但系统都报 noDialogueEntry=false，装完读不到剧情。根因是“有 string 参数就算能读”，不区分参数名。

## 改了什么
- src/Forge.Adapters.UnityMono/Internal/UnityMonoPlanner.cs：新增 DialogueParameterNameRx（整名匹配 dialogue/message/line/speech/say/caption/subtitle/content/body/sentence/text/name/speaker…）与 IsDialogueTextParameter(view)；hasDialogueEntry 增加这条判定。
- 关键点：locationText 这类“带 text 但不是台词”的参数不再误算（第一版用子串匹配就被它骗过，测试抓出来改成整名匹配）。
- 测试：Plan_OnlyNonDialogueStringParameter_RaisesNoDialogueEntryRisk、Plan_DialogueStringParameter_DoesNotRaiseNoDialogueEntryRisk。

## 验证
- UnityMono 测试 38 通过；全量 **718 通过 0 失败**（UnityMono 38，比上版 +2）。
- 未在真实游戏上重跑 plan（本版只有单测证据）。
