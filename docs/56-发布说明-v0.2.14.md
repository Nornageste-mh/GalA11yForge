# 发布说明：GalA11y Forge v0.2.14.0（2026-11-15）

状态：**已发布**，目录 `releases/v0.2.14/`。

## 1. 本版一句话

不朗读占位文本：`Empty` / `None` / `null` / `N/A` / `未设置` / `无内容` 这类占位字符串不再被当台词念；manosaba 真机 A/B 确认噪声 24 条 → 0 条，7 句真台词正常。

## 2. 改动

### 2.1 IL2CPP 运行时（`A11y/A11yRuntime.cs` 模板）

- 新增 `IsPlaceholderText(string text)`：先去掉 `[12] ` 这类索引前缀，再与 `Empty`/`None`/`null`/`N/A`/`未设置`/`无内容` 比较。
- `OnDialogue` 在空白串判定之后、去重之前丢弃占位文本，并累加 `_placeholderCalls`；
- `OnChoice` 同样过滤；
- `Shutdown()` 统计行改为：`朗读 N 行，空串 X 次，占位 Y 次，去重 Z 次`。

### 2.2 Unity Mono 的 `SpeechGate`（0.2.14 同版接入）

- `TryNormalize` 新增 `PlaceholderTextRx = ^(?:\[\d+\])?\s*(?:empty|none|null|n/a|未设置|无内容)$`，
  命中时写 `[Speech:placeholder] 跳过占位文本：…` 并返回 false（不朗读、不进历史缓冲）。

### 2.3 测试

- `FieldWiringTests` 断言 `PlaceholderTextRx`/`占位文本`；
- `PlanningAndGenerationTests` 断言生成的 `A11yRuntime.cs` 含 `IsPlaceholderText` 与“占位”；
- 全量 **638 通过 0 失败 0 跳过**（Il2Cpp 52、Generators 59）。
