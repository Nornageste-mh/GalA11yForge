# GalA11y Forge 0.2.67.0 发布说明

## 一句话
修正 verify 语音统计：[朗读] 回声不再重复计数——「有效朗读 N 行」不再虚高。

## 为什么做
32 子代理体检（research/127）发现：同一句会先以 \[Speech]\ 记一行、再以 \[朗读]\ 记一行（91 行日志统计成 98 行、44 个唯一句），导致 s-03「重复」判定失真，「有效朗读」数字也虚高。

## 改了什么
- \SpeechLogInspector\ 新增 \EchoLines\：\[朗读]\ 行的文本若已由 \[Speech]\/\[a11y-speech]\ 计过，就只算回声，不再进有效行/唯一句；
- metrics 增 \speechEchoLines\；
- 新增测试：\[Speech] 早春\ + \[朗读] 早春\ + \[Speech] 下雨了\ → 有效 2、唯一 2、回声 1。
