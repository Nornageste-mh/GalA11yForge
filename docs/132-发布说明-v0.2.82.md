# 0.2.82 发布说明：`--speech-log` 相对路径先按当前目录找

- 日期：2026-11-17
- 版本：0.2.82.0
- 上一版：0.2.81.0（IL2CPP 插件版本号跟随工具）

## 1. 一句话

`verify --speech-log 某日志.log` 以前会把相对路径当成“游戏目录里的相对路径”，在项目根目录执行时直接报“日志不存在”；现在先按当前工作目录找，找不到再退回按游戏目录解析。

## 2. 为什么

0.2.79 做 s-05 真机验证时踩到：在 `D:\DSHWorkSpace` 下执行、日志在 `research/...` 相对路径，结论是 `s-01 fail`、`overall=partial`——实际原因是路径解析口径不对，不是日志真的不存在。

## 3. 改了什么

- `src/Forge.Verify/Internal/SpeechLogChecks.cs` 的 `ResolveLogPath`：绝对路径不变；相对路径先 `Path.GetFullPath(相对路径)`（当前工作目录），存在就用；否则退回 `Path.Combine(游戏目录, 相对路径)`（旧行为）；都不存在才判“日志不存在”。
- CLI `--speech-log` 帮助文本同步说明这条口径。

## 4. 验证

- 新增 `tests/Forge.Verify.Tests/InstallVerificationTests.cs::Relative_speech_log_path_resolves_against_working_directory_first`（在当前目录写一个相对日志，断言 s-01/s-02 pass、overall=pass_with_skips）。
