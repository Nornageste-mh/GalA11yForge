# 0.2.81 发布说明：IL2CPP 插件的版本号跟工具一致

- 日期：2026-11-17
- 版本：0.2.81.0
- 上一版：0.2.80.0（全文件校验清单）

## 1. 一句话

以前 IL2CPP 生成的插件永远自称 `0.1.0.0`，日志里分不清是哪个工具版本生成的；现在跟工具版本一致（本版 `0.2.81.0`）。

## 2. 为什么

体检 research/143 把它列为待拍板项：「exe/插件版本仍是 1.0.0.0/0.1.0.0」。用户反馈问题时贴的日志只有 `无障碍补丁 0.1.0.0`，无法对应到是我们哪次发布的产物。

## 3. 改了什么

- `src/Forge.Adapters.Il2Cpp/Internal/Il2CppTemplates.cs`：删除硬编码 `internal const string PluginVersion = "0.1.0.0";`，`__VERSION__` 改为替换成 `GalA11yForge.Core.ForgeInfo.Version`；
- 新增断言：生成物 `Plugin.cs` 必须包含当前工具版本字符串。

## 4. 验证

- 全量 **741 通过 0 失败**（Il2Cpp 56）。
- 这次是单测级验证；没有重新构建并真机安装 IL2CPP 插件。
