# GalA11y Forge 0.2.61.0 发布说明

## 一句话
游戏根目录同时有“启动器”和“真游戏”时，不再锚到启动器——按同目录 exe、UnityPlayer、程序集大小和层级给每个 *_Data 打分，选真正的游戏。

## 为什么做
32 子代理体检（research/141）里 111《我与你共度的七日》是启动器 + game/ 双层结构，旧逻辑只扫顶层、顶层找到就返回，结果 6 个钩子全打在启动器工具提示上，正文一句读不到。根因是 UnityMonoDiscovery.FindDataDirectories 的“顶层有结果就提前返回”。

## 改了什么
- FindDataDirectories：去掉提前返回，统一用限深 3 的 BFS 收集所有含 Managed/Assembly-CSharp.dll 的 *_Data。
- ChooseDataDirectory 改为打分选择：同目录有同名 exe +40、有 UnityPlayer.dll +10、程序集大小最多 +30、名字像 launcher/setup/unins 等 -60、层级越深扣分。
- 新增 DiscoveryTargetTests.ChooseDataDirectory_PrefersRealGameOverLauncher 与 ..._KeepsRootGameWhenNoLauncherPresent。
