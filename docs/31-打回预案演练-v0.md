## 1. 引擎太少 / 未知程序

```powershell
# 空目录：识别为 unknown，退出码 0（不是失败），明确说后续只能走通用/人工路线
.\forge.exe detect --game <空目录> --json
# -> {"ok":true,"family":"unknown","confidence":0,"message":"未识别出已知引擎（unknown，置信度 0）；这不是失败，但后续只能走通用/人工路线。"}

# 未知引擎 analyze：明确 E_ENGINE_UNSUPPORTED，退出码 4
.\forge.exe analyze --game <空目录> --json
# -> {"ok":false,"code":"E_ENGINE_UNSUPPORTED","message":"未能识别引擎（unknown）；没有可用的分析适配器。"}
```

结论：识别层不会把未知程序硬套成已知引擎；分析层直接拒绝，不会产出假补丁。

## 2. 日文不承诺（沿用证据，未重跑）

- 本机无 ja-JP 语音（注册表与 Speech_OneCore 均无）；Windows OCR 仅 zh-Hans，中文引擎读日文 CER 61%。
- 产品口径：v1 不承诺日文朗读；日文游戏会给出"未验证"与替代方案（自装 ja 音色 / NVDA eSpeak NG，不随包）。
- 证据：`research/06-a11y/REPORT.md`、`research/12-ocr-fallback/REPORT.md`。

## 3. 安装风险（沿用真机证据，未重跑）

- Mono《五天一夜》：install 23 文件 / verify pass / rollback 还原 0、删除 23、清理 2、哈希不一致 0；原版启动 22 秒存活。
- IL2CPP《硅心》副本：install 232 操作 / rollback 还原 228、删 4；GameAssembly.dll、SiliconHeart.exe、global-metadata.dat 哈希不变。
- Ren'Py DDLC 副本：install 9 文件 / rollback 后 1260/1260 哈希一致。
- 证据：`docs/15`、`docs/25`、`docs/28`、`research/29-il2cpp-e2e/`、`research/28-renpy-overlay/`。

## 4. GUI 读屏

- 自动化证据：UIA 树 44 元素、0 空名；Tab 21 个停点顺序正确；Alt+1..5/Alt+V/Alt+D 可用；WASAPI loopback 录音证明按键时只有 NVDA 会话出声（6 段语音对应 6 次按键）。
- 未做：用户本人戴耳机逐项验收、625 字长文本连续朗读。
- 证据：`docs/30-GUI真实读屏验收结论-v0.md`、`research/37-gui-nvda-audio/`。
- 待办：docs/30 §3 的 6 步人工复核（用户回来后 10 分钟可完成）。

## 5. 跨平台

- 当前只发 Windows x64（`win-x64` 自包含）。Windows 10 19045 实测；Win11 未实测。
- 不承诺 macOS/Linux；如被要求，需重做语音/注入层（Tolk/SAAPI 均为 Windows）。

## 6. 依赖多

```powershell
.\forge.exe doctor --json
# -> ok:true；dotnet-runtime 检查通过（8.0.11）；adapters 内置 3 个（unity_mono/unity_il2cpp/renpy）；
#    ghidra 可选：已找到 Ghidra 12.1.4（env:GHIDRA_INSTALL_DIR）
```

- 主程序：自包含单文件，不要求用户装 .NET（doctor 里的 dotnet 检查是开发机口径）。
- BepInEx / Ghidra / Il2CppDumper：BYO（用户自备或按需下载），不随包。
- 结论：装完即可用；高级功能才需要额外组件。

## 8. 未知程序兼容模式（沿用 R22 结论）

- 只保证：标准控件窗口（UIA/Win32）逐条朗读、可访问文本 DOM、OCR 作为默认关闭的兜底。
- 自绘界面（LoveNest NW.js 0.54）实测读不到（整窗 23 节点全是外壳）；OCR 美术字体 CER 41.8%，不承诺。
- 证据：`research/33-external-reader/REPORT.md`、`docs/26`。

## 9. 漏读/重复读

- 生成物内置：SpeechGate 同文 2 秒去重、选项回显抑制、`Repeat` 缓冲/优先级、快进丢中间句。
- 真机日志可核：`[Speech]` 每句一条、`[Speech:choice-echo]` 抑制回显、`[Hook:*]` 计数。
- 未验证：多句快速连读的漏句率（需人耳/录音回放）。

## 11. 版权/合规（沿用 R16 结论）

- 结构优先分发：只发生成器+运行时，不发补丁成品/diff/游戏资源。
- 随包仅 MIT/Apache/BSD 与未修改 LGPL 二进制；GPL 工具（Textractor/Luna 等）用户自装。
- 不绕 DRM/反作弊、不碰在线游戏；首启风险告知、默认离线单机。

## 结论
