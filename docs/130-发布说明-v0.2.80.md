# 0.2.80 发布说明：发布包带全文件校验清单

- 日期：2026-11-17
- 版本：0.2.80.0
- 上一版：0.2.79.0（verify s-05）

## 1. 一句话

以前发布包只给 5 个关键文件的 SHA256，现在额外生成 `SHA256SUMS.all.txt`，覆盖发布目录里每一个文件（14 个），逐字节可核对。

## 2. 为什么

体检 research/143 把它列为“需拍板”的阻塞项之一：`SHA256SUMS.txt` 只覆盖 5/16 文件，用户没法验证其余内容没被动过。现在两张清单并存：

- `SHA256SUMS.txt`：关键文件（保持旧脚本兼容）；
- `SHA256SUMS.all.txt`：全部文件（0.2.80 起）。

## 3. 改了什么

`tools/release.ps1` 在生成关键清单后，递归枚举发布目录所有文件（排除两张清单自身），按相对路径排序写出 SHA256。

## 4. 验证

- 全量测试 **741 通过**（0.2.80 只改发布脚本与版本号）。
