# 0.2.75 发布说明：安装结果告诉你日志在哪、怎么自动核对

- 日期：2026-11-17
- 版本：0.2.75.0
- 上一版：0.2.74.0（台词入口保底名额）

## 1. 一句话

装完后不知道“到底念没念”，现在安装结果会直接给出日志路径和一条可复制的 `verify --speech-log` 命令。

## 2. 改了什么

`src/Forge.Cli/InstallNotice.cs`：

- `Compose(...)` 新增 `gameDirectory`、`engineFamily` 参数；
- 有游戏目录时追加一句：日志看 `<game>\BepInEx\LogOutput.log`（Ren'Py 是 `<game>\a11y_speech.log`），并给出 `forge verify --game ... --speech-log ... --json`；
- JSON `data.speechLogHint` = 日志绝对路径。

`src/Forge.Cli/PipelineCommands.cs` 调用点传入 `resolved.GameDirectory` 与 `resolved.Detection.Family`。

## 3. 验证

- 新增 `tests/Forge.Core.Tests/CliTests.cs::Compose_AddsSpeechLogHintForUnityAndRenpy`（unity_mono → `BepInEx\LogOutput.log`；renpy → `a11y_speech.log`）；
- 全量 **739 通过 0 失败**（Core 118）。
