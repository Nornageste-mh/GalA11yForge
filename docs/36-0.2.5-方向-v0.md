# 0.2.5 方向（草案 v0）

> 2026-11-15 03:15 起草。0.2.4.0 已发布（`releases/v0.2.4/`，612 测试）。本文件只定方向与门槛，不开工；等用户回来确认或按证据推进。

## 1. 一句话

0.2.5 的目标不是“加更多引擎”，而是把已经证明的路径**做稳、做广、可复验**：第二款/第三款 Unity Mono 真机泛化、GUI 人工验收回执、KKZ 真机闭环（需授权）、未知程序兼容模式从“轮询”升级为“事件订阅”，并把日文 TTS 的真实能力说清楚。

## 3. 发布门槛（0.2.5.0）

1. 全解决方案测试全绿（基线不低于 612）。
2. 本版新增/修改的每项能力都有真机或可复现证据；没有证据的写“未验证”，不进“已验证”列表。
3. 发布物 SHA256SUMS + README + docs 发布说明齐全；版本号继续 0.2.x。
4. 不新增“默认开启的写游戏目录”行为；安装/回滚仍走账本+备份。
5. 若 KKZ 仍未授权真机验证：继续只发设计文档，不发可执行资产。

## 4. 明确不做（本版）

- 不追更多引擎家族的“全家桶”宣传（26 条识别规则已够用，重点是文本捕获质量）。
- 不把 OCR 做进主链（R22：自绘美术字体 CER 41.8%，不可用）。
- 不承诺“万能”：未知程序只承诺标准控件/可访问文本；读不到会明确说读不到。
- 不做云服务、不做在线翻译默认开启、不收集遥测。
