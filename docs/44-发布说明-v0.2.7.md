# 发布说明 v0.2.7.0（2026-11-15）

## 一句话

0.2.7 修掉了 Unity Mono「字段兜底」方案里最烦人的一个洞：**第一句台词可能读不到**。现在钩子读不到文本时会延迟复查最多 4 秒，等游戏把字写进字段后补读。

## 本版改动

### 1. 延迟复查补读（主线）

- 问题来源：0.2.6 在 GalMaster 的真机复验（`docs/43`）发现，进入对话的第一句文本在 `ShowDialogue` 返回之后才写进实例字段；没有第二次钩子触发，于是第一句只进了重读缓冲、没有朗读。
- 实现：`SpeechGate` 在字段读取为空/未变化时登记一次延迟复查（`WeakReference` 保存实例，每 0.25 秒复查一次，最长 4 秒，同一实例只排一条）；`Plugin.Update()` 调用 `SpeechGate.Update()` 到点复查；命中则 `[Speech:fields] 延迟复查补读。` 并朗读；超时写 `[Speech:fields] 延迟复查超时放弃（N 个字段）。`
- 触发范围：只在字段兜底路径（无字符串参数、按实例字段读取）生效，不影响已有字符串参数钩子。

### 2. 诊断改进

- 新增 `[Speech:fields] 已登记延迟复查（N 个字段）` 与超时放弃日志，均只在 `[诊断] 详细日志 = true` 时输出。

### 3. 测试

- 全解决方案 **621 通过 / 0 失败 / 0 跳过**（Core 84、Verify 64、Detection 30、Generators 59、RenPy 35、UnityMono 31、Build 77、Gui 138、Il2Cpp 48、Ghidra 55）。
- 新增/更新：`FieldWiringTests` 断言生成物含 `ScheduleFieldRecheck`、`延迟复查`、`Plugin.cs` 含 `SpeechGate.Update()`；golden/evidence 随模板重新生成。
