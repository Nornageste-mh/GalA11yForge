# 成本分析（2026-11-15 版）

> 目的：把“做这个产品要花多少钱”算清楚，分成**已经花的**、**必须花的**、**可选花的**三类。
> 原则：不编造价格。凡是没查证过的单价，统一写“未确认”，并给出估算方法。

## 一、结论（先看这个）

- **必要成本：0 元。** 软件依赖全部开源/免费；测试用游戏是已有资产；语音通道用系统自带或用户已装的读屏。
- **已发生成本：0 元**（未购买任何游戏、语音包、翻译 API、签名证书）。
- **可选成本**：只有“想扩大测试面/提高音质”时才需要，见第四节；有明确上限（用户此前拍板：最多 ￥300）。

## 四、可选成本（花钱能换什么）

1. **日文语音包**（TTS 念日文台词）
   - 现状：本机没有日文 TTS，产品默认不承诺日文朗读。
   - 代价：商业日文 TTS（如 VOICEPEAK、A.I.VOICE 等）为一次性买断或订阅，**单价未确认**；开源替代（如 eSpeak NG）为 GPL-3.0，**不能随闭源发行包**。
   - 建议：先不做；若用户需要，先试听再买，且只在本机使用、不进发行物。

2. **商业读屏**（如争渡读屏 ZDSR）
   - 现状：本机已有（用户侧），产品运行时按指纹加载，不随包。
   - 代价：用户已有则 0 元；新购价格**未确认**。

3. **在线翻译 API**（把日文翻成中文再念）
   - 现状：当前版本**不联网翻译**，成本 0；只做“界面文本取翻译后版本”。
   - 代价：按字符计费，单价随服务商变化，**未确认**；估算方法：`单价 × 总字符数`，一款 20 万字 Gal 约 20 万～60 万字符（含重复）。
   - 替代：本地开源翻译模型（免费，但占内存/速度慢），或先只读原文不翻译。

4. **代码签名证书**
   - 现状：未购买，Windows SmartScreen 会提示“未知发布者”，家用可接受。
   - 代价：证书年费**未确认**；不买不影响功能。

5. **硬件/磁盘**
   - 现状：D 盘可用约 13GB；测试副本用完即删（已建立发布物保留策略，见 docs/60）。
   - 代价：若磁盘不足，加硬盘的钱另算（本文件不估）。

## 五、成本控制规则（已经落地）

- 大工具按需下载、不进发布包（dnSpyEx/Frida 只在本机 research 目录）。
- 发布物只保留最近几个版本（docs/60），旧版本说明与校验和永久保留。
- 测试一律对“副本”跑，不碰 Steam 原目录；副本执行后删除。
- 需要用户掏钱的动作（买游戏、买语音、买翻译额度）先报方案，不先斩后奏。

## 六、如果被打回“成本不合理”怎么答

- 本产品**免费 + 开源依赖**，用户侧零采购也能用；成本争议通常来自“要不要商业 TTS/翻译”。
- 回应顺序：①先证明当前 0 元方案可用（已有真机证据）；②需要增强时给 A/B：A=只用系统语音（0 元）、B=买日文 TTS（价格待查，先试听）；③翻译同理：A=不翻译（0 元）、B=本地模型（0 元但慢）、C=在线 API（按量付费，先小样本估算）。
- 所有价格在文档里标“未确认”，避免承诺后又变价。
