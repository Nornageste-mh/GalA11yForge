# 合规、保护与分发红线 v0

日期：2026-11-14　依据：`research/18-legal-ip/REPORT.md`（282 行）、`research/11-unpack-protect/REPORT.md`（310 行）、`docs/10` 相关 evidence。
这份文档回答三个问题：**我们能发什么、不能碰什么、发布前必须检查什么。** 结论会直接约束 W2-* 工作包与发布脚本。

## 0. 一句话结论

我们只发布「生成器 + 运行时注入器 + 引擎适配脚本」；**永不发布补丁成品、diff、资源包**。
保护器只检测不脱壳；商业壳、DRM、在线游戏一律不碰；对外明说"实验性、可能失败"。

## 1. 分发形态：结构优先（法律原因，硬约束）

- **发工具，不发修改后的软件**：用户在本地对自己的正版游戏运行生成器、本地安装；我们不做"某游戏的无障碍补丁下载"这种成品分发。
- 依据《计算机软件保护条例》第 16 条(三)：合法复制品所有人可为实际应用环境/改进功能性能作必要修改；但同条末句禁止"未经许可向任何第三方提供修改后的软件"——所以分发 diff / 替换文件的风险显著高于分发运行时工具。
- **美国 DMCA 没有游戏无障碍豁免**（重要纠偏）：2024 年第九次三年度规则（89 FR 2024-10-28，doc 2024-24563）第 18 类"视频游戏无障碍"因无人提交续期申请而未获续展（脚注 21 给出旧条款 37 CFR 201.40(b)(21)）。§1201(f) 互操作例外只是窄抗辩，**不能对外宣称"有例外"**。
- **Steam 合同风险**：SSA §2.G 禁止 reverse engineer/modify，§4.B 禁止 tamper with the execution，§4.D 可无通知封号。产品必须：首启风险告知（用户确认）、默认只处理离线单机、检测到在线/反作弊即停。
- 以后若要做"单游戏成品补丁"，只能走**厂商书面授权**这条路，不在 v0.x 计划内。

## 3. 保护/加壳边界（R11 实测结论）

- **先读归档，再决定碰不碰 exe**：多数 Galgame 台词在 `data.xp3`/`.rpa`/Unity 资源里，不在 exe；壳只挡"exe 侧 hook"这一条路。
- **唯一自动脱的壳是 UPX**（官方 `upx -d`，可脚本化、失败安全）。UPX 还原**不是字节级还原**：测试样本 sha256 变化、PE 校验和被清零 → 必须当新产物处理，**绝不覆盖原 exe**。
- 其余压缩壳（ASPack/MPRESS/PECompact/NsPack/Petite/FSG/kkrunchy）与商业保护器（Themida/WinLicense、VMProtect、Enigma、.NET Reactor）**只检测、报人工待办**：不 attach、不 dump、不提供解密算法/密钥。
- 检测必须多信号 + 引擎上下文 + 词边界匹配。本机修掉两个真实误报：
  - SenrenBanka.exe 的 `.adata/.bind` 是 KiriKiri Z 自带节，被误判 ASPack/binder；引入引擎签名后降到 review 0.32。
  - To the Moon/mkxp 的字符串 `"MPRESS"` 撞进 `"COMPRESSION"`；加词边界后 clean 0.00。
- 置信度阈值：`≥0.85 packed(high)`、`≥0.55 packed(suspect)`、`≥0.30 review`，否则 clean；**动作只看"能否自动处理"**（只有 UPX 走自动）。
- IL2CPP 元数据加密：`global-metadata.dat` 魔数应为 `FAB11BAF`，版本异常/字符串表越界→只检测；本机 5 作全部未加密。Unity Bundle：头不是 `UnityFS`/UnityPy 打不开→只检测。解析失败≠加密（先按版本选布局）。
- 归档实测（本机合法样本）：13 个 RPA-3.0、3 个 RGSSAD、20/20 个 .assets、3/3 个 AssetBundle 可只读解析；XP3/PFS/NSA/ARC 无合法样本，未实测（SenrenBanka 的 XP3 走已有补丁路线，不在本轮实验范围）。
- 工具许可：DIE(MIT)、pe-sieve(BSD-2)、UnityPy(MIT)、GARbro(MIT，无 CLI 不进流水线)、UPX(GPL-2.0+压缩产物例外) 可用/可选；GPL 调试/脱壳工具不随包。

## 4. 隐私

- 日志不记录台词、CG 路径、用户名；OCR 只在内存在处理；遥测默认关闭，开启需单独同意（PIPL 13/14/17/29）。

## 5. 发布前 10 项检查

见 `research/18-legal-ip/evidence/preflight-10-checks.md`（含命令、通过标准、签字栏）。最低限度：
1. 包内无游戏资源/台词/图片/音频；2. NOTICE 与实际组件一致；3. 无 GPL/专有二进制；4. LGPL 组件附源码地址；5. Il2CppInterop 改动 patch 随包；
6. 无绕 DRM/反作弊代码；7. 首启风险告知存在；8. 默认离线单机；9. 日志无敏感信息；10. 版本号与"未实测"标注属实。
