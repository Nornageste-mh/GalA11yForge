## 2. 人工检查（用户按 Gate A 执行，3 人内测前先自跑 1 次 pilot）

前置：NVDA 已装并在运行；游戏为本人 Steam 正版；先启动一次原版确认能正常玩。

| # | 任务 | 通过标准 |
|---|---|---|
| M1 | 双击安装/运行安装说明 | 5 分钟内完成；SmartScreen/杀软提示有明确下一步；无静默失败 |
| M2 | 启动游戏 | 15 秒内听到第一句（含"语音后端状态"提示）；无声音时必须说出失败原因 |
| M3 | 读剧情 | 连续 10 句无漏读、无重复读；角色名可辨认；中文标点停顿自然 |
| M4 | 选项 | 选项被朗读且编号清楚；选择后不重复播报上一句 |
| M5 | 菜单/存档 | 菜单项可听到并可用键盘操作；存档/读档不破坏游戏 |
| M6 | 回看/历史 | 能重读最近若干句（若 v0.1 实现），否则明确记录"未实现" |
| M7 | 快进/自动 | 快进时丢中间句可接受，但不得卡死、不得重复堆叠；自动模式跟随朗读 |
| M8 | 异常自救 | 故意制造一个错误（如先删插件 DLL 再启动），按 README 能恢复；恢复路径 ≤3 步 |
| M9 | 卸载 | 运行 uninstall 后游戏恢复原版；Steam 完整性检查通过 |
| M10 | 主观 | 1–5 分：延迟、音量/语速、漏读、整体可用性；记录"最想先修的三件事" |

Gate A（进入 Round B 前）：A1–A12 全绿；M1–M9 中无未修 P0；3/3 人无协助听到第一句；M8 自救路径被 1 人独立走通。
Gate B（对外发布前）：见 research/17-usability-test/REPORT.md 第 6 节；v0.1 不承诺 Gate B。

## 3. 问题分级

- P0 阻断：装不上/启动黑屏/完全无声音且无提示/卸载后游戏坏/崩溃/静默失败。
- P1 严重：漏读、重复读、选项不可选、菜单不可退、朗读延迟 >5s、日志泄漏台词。
- P2 一般：语气/停顿、提示文案、非关键功能缺失。
