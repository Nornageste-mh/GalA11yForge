# 0.2.57 发布说明：未命名角色占位不再念

## 一句话
兜底轮询不再念 `【 ? ? 】`（未命名角色占位），正常名字框（`【 韩冬 】`）照读。

## 背景
0.2.56 真机《钟塔 Belfry》里仍有 2 次 `【 ?  ? 】` 被念；这是游戏角色没给名字时的占位，读出来是噪声。

## 改了什么
`src/Forge.Generators/Templates/SpeechGateTemplate.cs` 新增 `WatchPlaceholderRx = new Regex("^【[\s?？]{1,12}】$")`，`CleanWatchText` 命中即跳过（只匹配括号内全是问号/空白，不影响正常名字）。测试 `FieldWiringTests` 增加 `WatchPlaceholderRx` 断言。
