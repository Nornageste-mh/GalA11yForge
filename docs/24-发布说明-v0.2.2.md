## 一、一句话

在 0.2.1.0（朗读/选项真机打通）之上，0.2.2.0 增加 **Ghidra 高级分析后端**（`analyze --advanced`），
修复 **IL2CPP 选点 P0 与警告误报 P2**，修复 **GUI 动态提示读不到（P1）**，并把 Ren'Py 覆盖层安装、
加载器兼容性预检、`--option` 运行选项、安装前基线等已验收能力纳入发布。

## 二、本版新东西

### 2.1 Ghidra 高级分析（`forge analyze --advanced`）
- 真正调用本机 Ghidra headless（BYO，不随包）；没有 Ghidra 时明确「未启用高级分析」、退出 0、写 unverified，不假成功。
- 产物：`01-analyze/analysis-ghidra.json` + `analysis.json` 的 `ghidra` 段；`doctor` 增加可选 ghidra 检查。
- 真实冒烟：SenrenBanka.exe 只读副本，153.8 秒 / 318 函数 / 0 候选 / `packed=true` —— 结论是「加壳/自保护导致静态分析无效，不代表没有文本」，如实写风险。
- 用法与选项见 `docs/21-Ghidra高级分析接入.md`。

### 2.2 IL2CPP 修复（来自 R21 真机）
- P0：方法名含 `Async`（或 AsyncStateMachine）的候选加 `N9=-60` 并封顶 60 分，不再被自动选为钩子——真机上补 async 方法会抛 `MethodAccessException` 卡死首行。
- P2：「补丁点都不含字符串参数」警告改为同时检查 `Description` 与 `Target`，IL2CPP 正常方案不再误报。
- 回归：`Il2Cpp` 48 测试、`Core` 77 测试；`forge plan` 在 Mono 上有文本钩子不警告、NEEDY 无文本钩子正确警告。

### 2.3 GUI 读屏修复（task-38 P1）
- 去掉「提示」「最近一次结果」两个固定 `AccessibleName`：WinForms Label 默认用 Text 作可访问名，动态文本（如执行结果摘要）现在能被 UIA/MSAA 读到。
- 说明：task-38 的 UIA 树/键盘走查证据在 `research/31-gui-nvda/REPORT.md`；本修复后未重跑 MSAA 探针（如实标注）。

### 2.4 其他已并入能力
- Ren'Py 覆盖层安装/回滚接入 CLI（`research/28-renpy-overlay`，DDLC 副本真机 9 文件安装/回滚/1260 文件哈希一致）。
- 加载器兼容性预检：`Unity Mono` 游戏若裁剪 .NET 基础库（mscorlib 缺 `Module.GetPEKind`），`detect` 标 `unsupported`，`build/install` 提前拒绝并给人工待办（`research/26-loader-compat`）。
- `--option key=value` 运行选项（覆盖 profile.options，不落盘）；`--bepinex` / `--rollback` / `--force` 说明补齐。
- 安装前基线 `05-deploy/baseline.json`：`verify --rollback` 自动加载并核对 m-07；回滚时 BepInEx 运行期生成物按白名单清理。
- 选项朗读/数字键选择（0.2.1.0 已发布，真机已验）。
