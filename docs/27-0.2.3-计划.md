## 三、风险与对策

- IL2CPP 名字门/交互卡点：R21 已知真实鼠标+空格无法推进；本版先打通“安装+加载+日志”，剧情推进卡点如实写并给后续方案（输入注入/脚本 API）。
- KiriKiri 实验碰 Steam 目录：只加 1 个临时 tpm+marker，全程快照，失败立即回滚；不碰 data.xp3 与 0.2.0.1 发布物。
- GUI 录音不一定能证明“NVDA 声音”：备选 Speech Viewer 文本+人工清单；任何情况下不写“已朗读”除非有证据。
- 外部读屏器被误解为“万能”：docs/26、README、发布说明统一话术“标准控件/可访问 DOM 可读”；OCR 默认关、标实验性。
- 并行写盘冲突：task-42 会动 src/Forge.Build 与 CLI；Lead 在此期间不改这些文件；集成时先 `git diff` 式核对（工作区非 git，用文件清单+时间戳）。
