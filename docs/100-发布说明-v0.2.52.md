# 0.2.52 发布说明：文本兜底轮询真机验证 + 降噪

## 1. 一句话

把 0.2.51 的「文本兜底轮询」第一次放进真实 Unity 游戏跑通：日志里确实读到了游戏文字；同时抓出两类噪声（TMP 富文本标签、纯数字/页码），本版修掉。

## 2. 真机怎么验的

- 样本：`D:\Steam\steamapps\common\Build`（Unity Mono，主程序 `5omeday.exe`）复制一份到工作区，Steam 目录不动；
- 用 `releases/v0.2.51` 安装（23 个文件），打开 `BepInEx/config/*.cfg` 的 `[诊断] 详细日志 = true`，重启后运行约 90 秒；
- 结果：`[Speech:watch]` 54 行、`兜底读到` 53 行、`[朗读]` 49 行；读到 `透明无色的房间`、`五重永夜`、`Start`、`Close`、`Gallery`、`Voice`、`SE`、`翻阅文章` 等真实游戏文字；
- 结束后 `verify --rollback`（pass_with_skips）并删除副本。

## 3. 发现的噪声与本版修法

| 噪声（真机日志原文） | 原因 | 修法 |
|---|---|---|
| `<u><size=50>Starlit Chronicles Studio</s…` | TMP 文本里的富文本标签被原样交给语音 | 新增 `CleanWatchText`：先剥 `<[^>]*>` 再 trim |
| `9`、`1/4` | 页码/FPS/计数类短数字被当台词 | `WatchNumberRx = ^[0-9]{1,3}(/[0-9]{1,3})?$` 命中则跳过 |

改动文件：`src/Forge.Generators/Templates/SpeechGateTemplate.cs`（`WatchMarkupRx`、`WatchNumberRx`、`CleanWatchText`，`ScanWatchType` 改用 `CleanWatchText(...)` 读取）。
