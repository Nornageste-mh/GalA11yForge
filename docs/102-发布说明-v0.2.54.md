# GalA11y Forge 0.2.54.0 发布说明

## §1 一句话

文本兜底轮询再降一类噪声：`Off` / `On` / `Windowed` / `FullScreen` 这类设置项取值不再被念；真机对照确认设置值泄漏为 0。

## §2 问题怎么发现的

0.2.53 真机对照（《Build》`5omeday.exe`）日志里，分辨率 `1280x720` 已过滤，但仍读到：

```
兜底读到：Off
兜底读到：On
兜底读到：Windowed
兜底读到：FullScreen
```

这些是设置界面的取值，不是剧情台词。

## §3 改了什么

`src/Forge.Generators/Templates/SpeechGateTemplate.cs`：

- 新增 `WatchIgnoreExact`（OrdinalIgnoreCase 的 HashSet）：`on/off/true/false/yes/no/none/auto/default/enable/enabled/disable/disabled/windowed/fullscreen/full screen`。
- `CleanWatchText` 在分辨率过滤之后再加一条：命中 `WatchIgnoreExact` 直接返回 `null`（不记、不念）。

测试 `tests/Forge.Generators.Tests/FieldWiringTests.cs` 增加断言：生成物 `Platform/SpeechGate.cs` 含 `WatchIgnoreExact` 与 `windowed`。

## §7 已验证 / 未验证

已验证：
- 生成物包含新过滤；单测与全解决方案测试全绿；

- Ren'Py 8.x 自造样本对照、高 DPI 布局等仍未做。

## §8 升级

- 装过旧版 Unity Mono 补丁的，先 `forge verify --rollback`，再用 0.2.54 重新 `install`。
- 想临时关掉兜底轮询：游戏 `BepInEx\config\<插件GUID>.cfg` 里 `[朗读] 文本兜底轮询 = false`。
