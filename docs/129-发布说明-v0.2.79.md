# 0.2.79 发布说明：verify 会核对日志里的错误行

- 日期：2026-11-17
- 版本：0.2.79.0
- 上一版：0.2.78.0（同主题，补指标导出；0.2.78 产物已被本版取代）

## 1. 一句话

以前 verify 只看「有没有朗读行」，补丁在日志里报了一堆 `[A11y错误]` 也可能判通过；现在会单独检查错误行，有错直接报失败。

## 2. 改了什么

- `src/Forge.Verify/SpeechLogInspector.cs`：新增 `ErrorLines` 与 `ErrorRx = @"\[A11y错误\]|Exception[: ]"`；
- `src/Forge.Verify/Internal/SpeechLogChecks.cs`：新增 s-05「日志里没有错误行」（P1）：错误行 >0 → Fail，否则 Pass；指标 `speechErrorLines`。

## 3. 验证

- 全量 **741 通过 0 失败**（Verify 73）。
- 真机（最小 Ren'Py 样本 + 归档日志）：`allChecks` = s-01 pass / s-02 pass / s-05 pass / s-03 pass，overall=`pass_with_skips`。
