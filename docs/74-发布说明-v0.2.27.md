# GalA11y Forge 0.2.27.0 发布说明

- 发布日期：2026-11-15
- 发布目录：`releases/v0.2.27/`
- 测试基线：**658 通过 / 0 失败**（Core 97、Verify 69、Detection 30、Generators 59、Ren'Py 37、UnityMono 31、Build 80、Gui 145、Il2Cpp 55、Ghidra 55）

## 这一版修什么

**问题**：Ren'Py 的确认框、退出确认等屏幕常用 `imagebutton`，按钮上没有文字。读屏用户只听到提示句，不知道屏幕上有几个按钮、按什么键继续——只能瞎按。

**现在的行为**：

1. 特殊屏幕（确认框/退出确认）播报追加按钮信息：
   - 按钮有文字时：「按钮：确认、取消」；
   - 按钮没文字时：「有 2 个按钮。按 Tab 切换，回车确认」。
2. 焦点落到没有文字的按钮上时，不再静默：播报「按钮 （没有可读文字，按 Tab 换一个，回车执行）」。
3. 输入框行为不变（提示 + 打字回显）。
