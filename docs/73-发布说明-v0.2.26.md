# 0.2.26 发布说明：Ren'Py 界面文字改播“翻译后文本”

- 版本：`0.2.26.0`（2026-11-15）
- 发布目录：`releases/v0.2.26/`
- 上一版：`0.2.25.0`

## 1. 本版修了什么

修一个真机发现的“读错语言”问题：

- 0.2.25 在《永恒与星辰与日常》确认框取证时，界面显示中文：
  「您确定要返回到标题界面吗？此操作将会使未保存的进度丢失。」
  播报却是英文原文：
  `Are you sure you want to return to the main menu? This will lose unsaved progress.`
- 根因：生成覆盖层取屏幕文字时用了 Ren'Py 的 TTS 接口 `_tts_all(raw=True)`。
  `raw=True` 返回的是**翻译前的 source text**，`raw=False` 才是屏幕实际显示的翻译后文本
  （Ren'Py 自己的读屏实现 `renpy/display/tts.py:428` 用的就是 `raw=False`）。
- 修复：
  1. `00_contract.rpy` 的 `_a11y_displayable_text` 优先 `_tts_all(raw=False)`；
     老版本无参数时回退 `_tts_all()`，再不行回退 `raw=True`。
  2. `03_menu.rpy` 新增 `_a11y_translate_text()`（`renpy.translate_string` 兜底再查一次翻译表），
     接入确认框/输入框等特殊屏幕、选项上方题目、选项文本；查不到就原样播报，不报错。

- 之前装过 Ren'Py 覆盖层的：先 `forge verify --rollback` 卸旧补丁，再重新 `analyze/plan/generate/install`，
