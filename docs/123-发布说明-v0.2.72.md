# 0.2.72 发布说明：语音指标不再永远是空对象

- 日期：2026-11-17
- 版本：0.2.72.0
- 上一版：0.2.71.0（占位空文件不再骗过识别）

## 1. 一句话

`forge verify --speech-log --json` 的 `data.speech.metrics` 现在有真数字（日志字节数、朗读行、去重行、占位、回声、Ren'Py 通道、钩子命中、兜底行）。

## 2. 为什么做

0.2.70 把 `speech` 扩成整块时，`metrics` 还是空对象——脚本只拿得到文字结论，拿不到数字。原因是指标实际记在报告层（`VerificationRun.Metric` → `Report.Metrics`），CLI 合并的是「检查项自己的指标」，所以永远空。

## 3. 改了什么

- `src/Forge.Cli/PipelineCommands.cs`：`data.speech.metrics` 合并时追加报告层里所有以 `speech` 开头的指标（`speechLogBytes`/`speechLines`/`speechValidLines`/`speechUniqueLines`/`speechPlaceholderLines`/`speechEchoLines`/`speechRenpyLines`/`speechHookHitLines`/`speechWatchLines`）。
- 其他输出不变。

## 4. 验证

真机（自造 Ren'Py 最小样本 + 0.2.44 归档日志，install → verify --speech-log → rollback）：

```json
{"speechLogBytes":1738,"speechLines":8,"speechValidLines":8,"speechUniqueLines":6,
 "speechPlaceholderLines":0,"speechEchoLines":0,"speechRenpyLines":2,
 "speechHookHitLines":0,"speechWatchLines":0}
```

- 证据：`research/125-speech-metrics/verify.json`
- 全量测试：**737 通过 0 失败**（Core 117、Verify 72、Ghidra 72、Generators 60、Detection 30、Ren'Py 37、UnityMono 43、Build 82、Gui 168、Il2Cpp 56）
