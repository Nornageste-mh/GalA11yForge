# GalA11y Forge 0.2.33 发布说明

- 版本：`0.2.33.0`
- 日期：2026-11-16
- 发布目录：`releases/v0.2.33/`
- 上一版：`0.2.32.0`（报告阻断待办结构化）

## 1. 本版做了什么

把报告里「非阻断的建议待办」也变成结构化、可直接播报的数据：

1. CLI `report --json` 的 `data` 新增 `suggestedTodos`：非阻断待办最多 3 条，每条形如 `M-A02 在 x64dbg/Textractor 中定位文本函数后人工接钩子`（只含编号 + 标题，不含台词）。
2. GUI 播报标签新增 `suggestedTodos=建议待办`；结果区会逐行念「建议待办：M-A02 …」。
3. 与 0.2.32 的 `blockingTodos` 对称：一个告诉你“哪些事没做就不能用”，一个告诉你“哪些事做了会更好”。

## 2. 为什么

0.2.32 只播报阻断项，读屏用户仍不知道还有哪些非阻断建议（例如“换 interop 路线会更稳”“用 x64dbg 定位文本函数”）。信息不完整时，用户无法判断“这补丁到底差多少”。
