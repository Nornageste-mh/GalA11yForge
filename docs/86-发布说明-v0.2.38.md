# GalA11y Forge 0.2.38.0 发布说明

- 发布日期：2026-11-16
- 上一版：0.2.37.0
- 发布目录：`releases/v0.2.38/`
- 性质：读屏体验补强（把 0.2.37 的耗时数据念出来）

## 1. 这版解决什么问题

0.2.37 已经把高级分析的 `executableSizeBytes` / `estimatedSeconds` / `elapsedSeconds` 写进 JSON 和产物，
但 GUI 的结果区是按字段名念的：读屏用户会听到 `estimatedSeconds：402` 这种英文键，仍然不友好。

这版给这些字段补了中文标签，GUI 结果区（读屏播报/朗读文本）会念成：

```
高级分析：
  状态：timeout
  分析程序：D:\Steam\steamapps\common\SenrenBanka\SenrenBanka.exe
  分析程序大小（字节）：4583168
  预计分析耗时（秒）：402
  实际分析耗时（秒）：30.1
  选项警告：无
```

## 2. 改动清单

- `src/Forge.Gui.Core/ForgeDataNarrator.cs` 新增标签：
  - `ghidra` → 高级分析
  - `executable` → 分析程序
  - `executableSizeBytes` → 分析程序大小（字节）
  - `estimatedSeconds` → 预计分析耗时（秒）
  - `elapsedSeconds` → 实际分析耗时（秒）
  - `optionWarnings` → 选项警告
- `tests/Forge.Gui.Tests/NarrationTests.cs` 新增 `GhidraEstimateAndDurationGetReadableLabels`：
  用 0.2.37 的真实数据形状验证六行中文输出顺序与缩进。
