# 发布说明 v0.2.45（自造 Ren'Py 样本抓出的三处真问题）

## 1. 一句话

用一个「零美术资源、完全自造」的最小 Ren'Py 6.99 工程做真机验收，抓出并修掉了三处我们自己的问题：
**引擎会把 `os` 从脚本命名空间删掉导致 SAPI 语音一句都发不出去**、
**选项屏把题干当成第 1 个选项播报**、**生成的 .rpy 里文档字符串夹 ASCII 双引号导致引擎报语法错误**。

## 2. 为什么要自造样本

之前 Ren'Py 的验收都借真实游戏（DDLC、《永恒与星辰与日常》）。真实游戏能证明「能用」，但不好证明「边界」：

- DDLC 没装旧 a11y 补丁，测不出旧补丁冲突（0.2.24 才靠《永恒与星辰与日常》发现）；
- 真实游戏的选项、确认框出现的时机和内容都不受控，很难反复复现同一场景；
- 有些游戏必须经 Steam 启动（如 `mei`），自动化成本高。

所以本轮复制 DDLC 的 Ren'Py 6.99 引擎和运行时，自写 `game/script.rpy` + `game/screens.rpy`，
做一个只有两句对白、一个选择题、一个确认框的最小工程（中文用系统 `simhei.ttf`），
再在里面装我们的覆盖层跑真机。

## 3. 改动

### 3.1 SAPI 语音真正没声的原因（最重要）

- 现象：日志每句都报 `[A11y错误] sapi.speak: NameError: global name 'os' is not defined`；
  `wscript.exe` 从未启动 → 用户什么都听不到，但日志里「后端=SAPI」看起来很正常。
- 根因：`renpy/common/00keymap.rpy` 的 `init -1600 python:` 块里 `import os` 用了
  `config.screenshot_pattern`，随后 **`del os`**。我们的覆盖层在 `init -1850/-1800` 先跑，
  引擎 -1600 后跑，把 store 里的 `os` 删了；运行期任何 `os.xxx` 都是 NameError。
  （同一块 import 的 `codecs`/`sys`/`ctypes`/`subprocess`/`tempfile` 都没被动，所以只有 `os` 中招。）
- 修复：契约层改成 `import os as _a11y_os`，所有模板统一引用 `_a11y_os`；
  测试加了回归守卫：生成物里不允许出现裸 `os.`。
- 真机验证：修复后同类日志 0 条，`wscript.exe` 进程实际出现。

### 3.2 选项题干被当成第 1 个选项

- 现象：`[A11y菜单] 选项 3 个：1 问题是：你要去哪里？；2 去公园；3 回家`（题干占了一个编号，选项编号全错）。
- 根因：Ren'Py 的 choice 屏惯例是 `textbutton i.caption action i.action`，
  题干这一项的 `action` 是 `None`，但它仍然是个可聚焦按钮，会进 `focus_list`。
- 修复：新增 `_a11y_button_has_no_action()` 过滤「没有动作的假按钮」；
  选项统一由 `_a11y_choice_options()` 取，题干单独由 `_a11y_choice_prompt()` 播报。
- 真机验证：`提示：问题是：你要去哪里？。选项 2 个：1 去公园；2 回家`。

### 3.3 生成的 .rpy 文档字符串夹 ASCII 双引号 → 引擎解析失败

- 现象：Ren'Py 启动弹「Parsing the script failed」，`03_menu.rpy line 296: invalid syntax`。
- 根因：新加的帮助函数用了 `"""…"""` 文档字符串，正文里夹了 ASCII 双引号。
- 修复：该处改成 `#` 注释；并把「模板 .rpy 不要用夹 ASCII 双引号的文档字符串」写进打回预案。

## 7. 已验证 / 未验证

已验证：

- 发布包 `forge version` = 0.2.45.0；`detect` 对真实游戏 `Build` = unity_mono 95%、loaderCompat=supported；
- 最小样本真机：SAPI 无 NameError、`wscript.exe` 起进程；选项题干与选项分离；确认框整屏播报；
- 回滚：`verify --rollback` 能清理本工具装的覆盖层（本样本因反复 `--force` 覆盖安装，账本把已有覆盖层

未验证：

- 确认框按钮的「点击激活」动作（只验证了播报）；
- Ren'Py 8.x（本样本是 6.99；8.6 的回归见 `research/66`）；
- ZDSR/Narrator、高 DPI 布局。

## 8. 升级提示

- 本版修的是 **Ren'Py 覆盖层模板**（`game/a11y_platform/*.rpy`）。已装过旧覆盖层的游戏，需要：
  `forge verify --rollback --force` → 重新 `forge install`，让新模板生效。
- Unity / IL2CPP / Ghidra 路线不受影响。
