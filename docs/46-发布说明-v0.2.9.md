# 0.2.9.0 发布说明

发布日期：2026-11-15
版本纪律：按用户 2026-11-14 邮件要求，统一在 0.2.x 上叠加。

## 1. 本版做了什么

### 1.1 错误信封补 details（CLI）

`CliResponse` 增加 `details`（字典，可选）：回滚/安装部分失败时，把「哪个文件、为什么」这类结构化原因带出来，而不是只有一句汇总消息。

- JSON 模式：`{"ok":false,"code":"E_PARTIAL","message":"…","details":{"plugin/a11y.dll":"删除失败：文件被占用"}}`
- 文字模式：在「建议」之后逐条打印「详情 key：value」。

### 1.2 GUI 显示 details

`ForgeEnvelope` 解析 `details`，`ForgeRunOutcome.Details` 暴露给结果区；
`ForgeResultTextBuilder` 在「建议」之后输出「详情：」并逐条换行，读屏可逐行朗读。

### 1.3 由来

0.2.7 真机排查回滚问题时，CLI 曾报 `E_PARTIAL` 但细节被省略，只能翻日志推断；
这版把细节补回信封，改善「出问题时的可诊断性」。
