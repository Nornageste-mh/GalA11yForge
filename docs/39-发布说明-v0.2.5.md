# 0.2.5.0 发布说明

- 状态：已发布（2026-11-15）
- 发布目录：`releases/v0.2.5/`
- 测试基线：**618 通过 0 失败 0 跳过**
- 上一版：0.2.4.0（`releases/v0.2.4/`，612 测试）

## 1. 一句话

这一版修了一个“泛化缺口”：有的游戏把台词写在**实例字段**里（钩子方法本身没有字符串参数），生成器现在会按分析证据反射读字段并朗读，不再只能“计调用次数”。在第一款非测试目标的 Unity Mono 游戏 GalMaster 上真机听到了剧情。

## 2. 本版改动

### 2.1 字段兜底朗读（新功能）

- `UnityMonoPlanner`：把候选证据里的「类型文本字段：…」写进补丁点描述。
- `GeneratorSettings`：解析字段名（只接受合法标识符），无字符串参数但有实例文本字段的钩子也可当主朗读。
- 生成物：`Hook_*.cs` 用 `Postfix(object __instance)`；`Platform/SpeechGate.cs` 新增 `SayFields/NoteFields`，反射取字段（string 直接读，否则取 `text` 属性），拼接、去重后走 `Repeat.Say/Note`。
- 安全：反射失败只写 `[Speech:fields]` 诊断，不影响游戏；不引用 `Assembly-CSharp`（纯反射）。
- 测试：`tests/Forge.Generators.Tests/FieldWiringTests.cs` 4 个用例；golden 重生成。

### 2.2 安装更省事

- `forge install` 自动解析 BepInEx 离线包（工作区 → exe 目录 → 进程目录 → `app\bepinex\`），Mono 不再要求手动指定；IL2CPP 仍只认显式 `--bepinex`（版本不同，避免拿错）。
- `PluginDeployer` 缺包错误文案改为 `--bepinex <zip>`，与 `--help` 一致。

### 2.3 人工待办动态化

- `UnityMonoPlanner.BuildRisks/BuildManualTodo` 改为按本次计划生成：风险带实际入口名；选项/对话待办按候选条件出现。
- 删除此前从别的作品抄来的硬编码（`DOText/HandleMessageText/AnimateText`、“67.7/416.2 秒”等），避免误导。

### 2.4 verify 更诚实、报告不覆盖

- 新增 `IsPatchInstalled`（读安装账本 + 逐文件哈希复核）：确认未安装/已卸载时输出 `overall=not_installed`、明确写“跳过安装后自检，这不等于通过”、退出 0。
- `RunVerifyAsync` 额外写 `verify-<yyyyMMdd-HHmmss>.md` 存档；`verify.md` 保留兼容。

### 2.5 “没有文本来源”警告判定扩展

- `PatchPlanTextInspector.HasTextSource`：有字符串参数**或**有“类型文本字段”都算可朗读来源；避免对字段兜底型计划误报“只能计调用次数”。

### 2.6 KKZ（吉里吉里旧版）

- 仍只发设计文档，不发可执行资产。
- 本版期间发生过一次实验脚本误删真实游戏目录的事故，已完整恢复并加固脚本；通报警示见 `docs/38-事故通报与恢复记录-v0.md`。该事故不涉及产品代码路径。
