## 四、并行写入冲突纪律

- 子代理在写 `src/**` 时，Lead 不并发构建/改同一项目；以文件时间戳与最后修改判断收尾。
- 集成后若出现编译错误，先看是不是两个子代理改了同一文件；必要时隔离提交（workspace 非 git，先复制备份）。
- 每完成一项集成，立即跑该项目的单元测试，再跑全量；不要把多个项目改动堆到最后一起跑。
