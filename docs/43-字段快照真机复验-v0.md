## 三、操作坑（下次直接照做）

1. 不改 `BepInEx\config\<guid>.cfg` 的 `[诊断] 详细日志 = true`，日志只有启动信息，看起来像“钩子没触发”。
2. 屏幕 `y≈955–1000`、`x≈48–880` 有 `Microsoft Text Input Application` 幽灵窗口；点菜单按钮要用 `(140, 1005)` 这种在它下缘之外的坐标，否则点击被吃掉。
3. 窗口要先 `topmost.ps1 -TargetPid <pid> -On` 置前台再点；游戏进程 PID 会在启动几秒后变化（引导进程→正式进程），以 `Get-Process | Where ProcessName -like 'GAL*'` 为准。

## 四、0.2.7 修复方案（建议）

**问题**：钩子返回后才赋值的文本永远赶不上钩子。  
**最小修法**：钩子命中后把 `__instance` 存进 `WeakReference` 并登记“延迟复查”；`Plugin.Update` 里约 200ms 后再跑一次 `CollectFields`，有新文本就朗读，随后注销。只在本次返回 null（字段为空/相同）时登记，避免每次钩子都复查。  
**验收**：单测覆盖“延迟复查只发一次 + 2 秒同文去重仍生效”；真机重跑本记录脚本，首句应出现 `[Speech]`。
