# 发布说明 v0.2.3.0（2026-11-15）

状态：**已发布**（本地发布目录 `releases/v0.2.3/`）。
版本号纪律：按用户 2026-11-14 邮件，统一在 `0.2.x` 叠加，本版是 `0.2.3.0`。

## 1. 一句话

本版把两类引擎的**安装/回滚闭环**补上（IL2CPP 与 Ren'Py），修掉两处真机"假失败/假通过"，并把 KiriKiri 老作品的路线摸清（结论：不能靠丢 `tpm` 一键，需要代理注入；本版不自动安装）。

## 2. 本版改了什么

### 2.1 IL2CPP 构建/安装链（task-42）

- 新增 `src/Forge.Build/BepInEx6Package.cs`、`Il2CppInteropProbe.cs`、`Il2CppPluginDeployer.cs`；CLI 的 `build/install/verify --rollback` 对 `unity_il2cpp` 真正可用。
- 真机（《硅心》副本，BepInEx 6.0.0-be.788 + Il2CppInterop）：build 6.7 秒产出插件；install 232 个文件操作；游戏内连续 **19 行** `Naninovel.UI.RevealableUIText::set_Text` 命中；回滚后 `GameAssembly.dll`/`SiliconHeart.exe`/`global-metadata.dat` 哈希不变、interop 97 文件保留。
- 无 interop 时不再返回 `E_NOT_IMPLEMENTED`，改为 `E_DEPENDENCY_MISSING` + 四步指引（装 be.788 启动一次 / 用 Il2CppDumper dump.cs / 重试 / 看报告）。

### 2.2 Mono 基线假失败修复

- `src/Forge.Build/DeploymentBaseline.cs` 新增 `TrimRuntimeChurn`：安装前基线剔除 `BepInEx/interop|cache|patchers` 与 BepInEx 根日志（Mon 保留 `config` 以维持 m-07 覆盖）。
- 原因：这些文件每次启动必变，留在基线里会让 Verify 的 m-07「账本外原文件未变」把正常启动当成篡改（R22 NEEDY、R21 IL2CPP 都踩过）。

### 2.3 GUI 真实读屏验收（task-43，部分验证）

- 两轮 WASAPI loopback 录音：逐 0.3 秒、逐进程采样，只有 `nvda.exe` 会话非零（59 个采样 >0.001，峰值 0.7659）；6 段语音与 6 次按键一一对应（延迟 0.31–2.07 秒）。
- NVDA 朗读查看器记录到控件名、帮助文本、`Alt+1/2/V` 与动态「正在执行/最近输出/完成」→ 0.2.2 修的动态文本可访问名有效。
- 未验证：用户实际听见全文（625 字连续朗读失败）、`Alt+O/3/4/5`、`Ctrl+Shift+R`。详见 `docs/30-GUI真实读屏验收结论-v0.md`。

### 2.4 KiriKiri 研究（task-44/45/46，不进本版功能）

- 官方 krkrz 1.4.0.8：`plugin\*.tpm` 在 `startup.tjs` 前自动加载、V2Link 时 TJS 已就绪、可调 TPM 原生方法（阳性对照 1.7 秒写出 marker）。
- SenrenBanka 1.2.0.3：**不自动加载** `plugin/*.tpm`（4 次启动 marker 全无；32 位模块表 111 项无探针）；`.sig` 未强制。回滚后 59 个 plugin 文件 + 33 个根文件逐哈希一致。
- 替代路线：替换/代理已被 `Plugins.link` 加载的 `plugin\*.dll`（在《千恋》上代理 `menu.dll` 可加载、可调 TJS，主菜单可交互）；脚本级包装 `MessageLayer.processCh` 已在实验环境捕获整行。**本版不提供 KKZ 自动安装**，只如实识别 + 人工待办。

### 2.5 其它

- CLI 新增 `--option key=value`（覆盖 profile.options，不落盘）与 `--speech-runtime`（IL2CPP 语音运行时选择）。
- Verify 的 m-07 文案降噪：全部为新增文件时不再报"无安装前哈希"。
- 回滚时 BepInEx 运行期生成物自动清理（0.2.1 起），本版补上 Mono 侧基线剔除。
