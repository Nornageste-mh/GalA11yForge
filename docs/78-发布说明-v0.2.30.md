# GalA11y Forge 0.2.30.0 发布说明

版本：0.2.30.0（2026-11-16）
发布目录：`releases/v0.2.30/`
测试基线：**662 通过 / 0 失败 / 0 跳过**

## 1. 本版改了什么

### 1.1 修复：GUI「高级分析」复选框被裁切（0.2.29 的回归）

0.2.29 给 GUI 加了「高级分析」复选框（Alt+7），但输入区根布局第 0 行是固定高度 234F，而 7 行输入（7×32=224）加分组内边距（约 32）需要约 256F——最后一行被容器裁掉。

表现很隐蔽：

- UIA 无障碍树里**能读到**这个控件（42 个节点全有中文名，Alt+7 也能聚焦）；
- 但窗口画面里**看不到**它，低视力用户和鼠标用户等于没有这个功能。

修复：`src/Forge.Gui/MainForm.cs` 根布局第 0 行 `234F` → `268F`。

教训记入 `docs/77`“已知问题”和 `docs/78` 本文件：**可访问性测试不能只看 UIA 树，还要看实际画面**。

### 1.2 新增：GUI 复选框真机 E2E 脚本 `tools/gui-advanced-e2e.ps1`

目标：证明“用户在 GUI 里勾选「高级分析」→ 点「分析文本」→ 真的调用了 Ghidra”，而不是只验证参数拼装。

脚本用 Win32 消息驱动（不依赖焦点/UIA）：

- 用 `WMI Win32_Process.Create` 分离启动 GUI（避免子进程继承本进程管道导致命令挂起）；
- `EnumChildWindows` 找输入框，`WM_SETTEXT` 填「游戏目录」「工作区」；
- 按控件文本找「高级分析」复选框与「分析文本」按钮，`BM_CLICK` 触发；
- 轮询工作区 `analysis.json` 与 `analysis-ghidra.json`，以 `available=true` 作为 Ghidra 真跑过的判据；
- 同时记录 `forge.exe` 子进程命令行，确认 `--advanced` 确实传了。
