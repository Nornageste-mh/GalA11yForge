# 0.2.15.0 发布说明（2026-11-15）

## 1. 一句话

IL2CPP 的字段兜底不再乱念界面字：装饰性容器（格子/列表项/文件夹…）不再进候选，对话宿主优先占名额，每款游戏最多自动放 2 个字段兜底入口。

## 2. 本版改了什么

### 2.1 装饰性宿主类型排除（分析阶段）

`Il2CppPatterns` 新增 `FieldHostExcludeRx`，在 `Il2CppAnalyzer.IsFieldFallbackCandidate` 里对声明类型名直接跳过：

- 规则：`(cell|slot|item|folder|grid|list|tab|scroll|button|toggle|badge|icon|avatar|thumbnail|photo|sprite)`
- 由来：0.2.12 真机里 Lilith 的 `GiftCellView._text` 把「一个饰品的名字」当台词读、`LilithFolderView` 会读界面字。

### 2.2 对话宿主优先 + 展示动词再加权（分析阶段）

- `FieldHostPriorityRx = (dialogue|dialog|chat|bubble|subtitle|caption|speech|story|say)`：宿主命中 → 字段候选补到 56 分。
- 同一宿主里方法名命中 `Show/Display/Print/Render/Reveal/Set/Refresh/Populate/Fill/Type` → 补到 60 分。
- 效果：`DialogueBubbleUI::ShowNode`、`ShowOptions` 排到最前，不再被 `LocalizedText::RefreshText`、`MemoFullView::RefreshAll` 挤掉。

### 2.3 字段兜底名额上限（计划阶段）

- `Il2CppPlanner.MaxFieldFallbackHooks = 2`：每款游戏最多自动放 2 个字段兜底入口。
- 超出名额的候选不再“静默消失”，而是生成一条人工待办：「字段兜底名额已满（人工确认）：<方法>」，附候选证据，方便用户自己决定要不要接。

## 3. 证据

- 单测：`Analyze_DecorativeHostType_IsNotFieldFallbackCandidate`、`Plan_CapsFieldFallbackHooksAtTwo`；Il2Cpp 测试 52 → 54，全解决方案 **640 通过 / 0 失败**。
- Lilith 计划对比（同一游戏、只读分析）：
  - 改前：6 个钩子（2 条 DOTween setter + `Apply*`/`Handle*` + `MemoFullView×3`）。
  - 改后：**2 个钩子**——`DialogueBubbleUI::ShowNode`、`DialogueBubbleUI::ShowOptions`，均 60 分。
- Lilith 真机（手工放 DLL 进 `BepInEx\plugins`，不经 forge install）：
  - `[Speech:fields] hook=DialogueBubbleUI::ShowNode field=_dialogueText len=4`
  - `[a11y-speech] DialogueBubbleUI::ShowNode：周末快乐`
  - 噪声计数：`GiftCellView` 0、`LilithFolderView` 0、`MemoFullView` 0。
- 证据文件：`research/50-il2cpp-field-fallback/evidence/lilith-0.2.15-two-hooks-runtime-LogOutput.log`、`lilith-0.2.15-two-hooks-lines.txt`、截图 `_il2cpp-field-e2e2/runtime/shot-0215-play.png`。
