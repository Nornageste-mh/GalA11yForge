# GalA11y Forge 0.2.21 发布说明

日期：2026-11-15
上一版：0.2.20.0
本版类型：功能补全（GUI 也能做“语音证据”自动检查）

## 一句话

0.2.20 让命令行能自动回答“补丁到底有没有读出台词”；0.2.21 把这件事搬进图形界面——填一下日志路径，点“安装后自检”，结果区直接告诉你“有效朗读多少行、有没有重复、有没有占位噪声”。

## 改了什么

### 1. GUI 新增「语音日志（可选）」输入框（Alt+5）

- 位置：输入区第 5 行，带「浏览…」按钮（文件类型 `*.log;*.txt`）。
- 只有「安装后自检」会用到它：把路径传给 CLI 的 `--speech-log`，其它命令自动忽略。
- 留空也能用：自检会按默认位置找 `BepInEx\LogOutput.log` 或 Ren'Py 的 `a11y_speech.log`。
- 就绪提示里加了说明：“自检时可在「语音日志」里填游戏运行日志，自动检查补丁有没有读出台词。”

### 2. GUI 结果区能读出「语音证据」

- CLI 的 verify JSON 信封新增 `data.speech`（检查编号、名称、状态、说明、统计）。
- GUI 的朗读/结果展示把 `speech`、`speechLines`、`speechValidLines`、`speechUniqueLines`、`speechPlaceholderLines`、`speechLogBytes` 等字段翻成中文再读，例如：
  - `语音证据：有效朗读 19 行，去重后 18 行，占位噪声 0 行。`
  - `有效朗读行：19`
  - `占位噪声行：0`

### 3. CLI 人类可读输出也加了一行

`forge verify` 写完报告后，若找到 `s-02` 检查，会在「报告：…」下面补一行：

```
  语音证据：有效朗读 19 行，去重后 18 行，占位噪声 0 行。
```

### 4. 快捷键顺延

新增输入框后，「演练模式：只检查、不写盘」的助记符由 Alt+5 改为 **Alt+6**（Alt+1..5 为输入区）。

## 已验证 / 未验证

**已实测**
- 开发版 CLI：对 manosaba 安装（229 文件，deployment `dep-20261115-113922-8c69`）→ `verify --speech-log <归档日志>` 人类输出出现「语音证据：有效朗读 19 行，去重后 18 行，占位噪声 0 行。」→ `--rollback` 还原 228 / 删除 1 / 哈希不一致 0，插件目录恢复原样。
- 发布版 `forge help` 显示 `--speech-log` 与 `--speech-runtime` 说明。

**未验证 / 已知边界**
- GUI 窗口里的新输入框尚未用 NVDA 人工点一遍（建议你实际开一次界面，按 Alt+5 试试；Alt+6 演练）。
- 「语音证据」只统计日志行数，不等于用户真的听见；Tolk 缺失时补丁降级为日志输出。
- Ren'Py 确认框真机取证仍未完成（机制同源、单测覆盖）。
- 0.2.20 的已知边界继续有效：没有运行日志时只会标记“未验证”，不会假装通过。
