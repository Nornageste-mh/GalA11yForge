# GalA11y Forge 0.2.66.0 发布说明

## 一句话
\orge doctor\ 新增「日语语音」可选检查：本机没有日语语音时明确告诉你——日语台词会被按中文/英文念，或读不出来。

## 为什么做
32 子代理体检（research/129 打回预案演练）指出：日语 TTS 是最容易被打回的一条（本机 0 个日语语音、SAPI 不 SetVoice、没有 ja-JP 检测）。产品至少要提前说清楚，而不是让用户装完补丁才发现“没声”。

## 改了什么
- 新增 \src/Forge.Core/Tools/VoiceProbe.cs\：读 SAPI 与 OneCore 的语音 token（\eg query\，5 秒超时、失败不抛），\IsJapaneseVoiceName\ 按 ja-jp/haruka/ayumi/ichiro/nanami/keita 等关键词判定；
- \orge doctor\ 新增可选检查 \japanese-voice\：找到时列出前 3 个，没找到时给出「设置 → 时间和语言 → 语音」的安装提示；
- 新增测试：7 组名称判定 + 1 条「Probe 不抛异常」。

## 验证
- 本机实测：\orge doctor --json\ 输出 \japanese-voice\ 检查（optional=true, passed=false），与本机只有中英文语音一致；
- Core 116 通过（+8）；全量 **732 通过 0 失败 0 跳过**（Detection 30、Generators 60、Ghidra 72、Gui 168、UnityMono 41、RenPy 37、Il2Cpp 56、Verify 70、Core 116、Build 82）。
