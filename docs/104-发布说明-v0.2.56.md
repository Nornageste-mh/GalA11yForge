# 0.2.56 发布说明：兜底轮询不再念 `New Text`

## 一句话
Unity 界面里的默认占位文本（`New Text` 等）不再被念出来，减少菜单/设置里的无效朗读。

## 背景
0.2.55 真机《钟塔 Belfry》日志里，`New Text` 这类 Unity 默认文本被当台词念；用户听到会误以为补丁在乱读。

## 改了什么
`src/Forge.Generators/Templates/SpeechGateTemplate.cs` 的 `WatchIgnoreExact` 增加：`new text`、`new text (legacy)`、`text`、`???`、`? ?`（大小写不敏感、精确匹配），`CleanWatchText` 命中直接跳过。

## 真机对照（《钟塔 Belfry》只读副本）

| 指标 | 0.2.55 | 0.2.56 |
|---|---|---|
| 日志行数 | 577 | 742 |
| 兜底读到/朗读 | 184 / 184 | 239 / 239 |
| `New Text` 被念 | 有 | **0** |
| 异常 | 0 | 0 |

真实台词照读（「在梦里，总是会有十二声钟响…」「「小冬！」」等）。还剩 `【 ?  ? 】`（未命名角色占位）会被念。

## 测试
全量 713 通过 0 失败（Core 105、Verify 69、Detection 30、Generators 60、RenPy 37、UnityMono 35、Build 82、Gui 168、Il2Cpp 55、Ghidra 72）。
