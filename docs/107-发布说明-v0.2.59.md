# GalA11y Forge 0.2.59.0 发布说明

## 一句话
orge verify --speech-log 现在会区分「钩子命中正文」和「全靠兜底轮询」：如果日志里有朗读、但钩子 0 命中、只有兜底轮询读到，会记 s-04 跳过并写未验证，**不再让人误以为剧情读到了**。

## 为什么做
32 个子代理体检（research/122）发现：8 份真机日志全是「6 个钩子挂载、0 命中、兜底 21–245 句」，旧 verify 只看到“有朗读行”就认为正常。兜底轮询只能证明读到了某个文本组件，不能证明读到剧情正文。

## 改了什么
- src/Forge.Verify/SpeechLogInspector.cs：新增 HookHitLines（匹配 [Hook…] 命中）与 WatchLines（匹配 [Speech:watch] 兜底读到）两个统计。
- src/Forge.Verify/Internal/SpeechLogChecks.cs：metrics 增加 speechHookHitLines/speechWatchLines；新增 s-04 检查——钩子 0 命中且兜底 >0 → Skip + Unverified；有钩子命中 → Pass。
- 测试：	ests/Forge.Verify.Tests/SpeechLogInspectorTests.cs 新增 Counts_hook_hits_and_watch_fallback_lines。

## 验证
- Verify 测试 70 通过；全量测试 **716 通过 0 失败**（Verify 70；其余套件同期全绿）。
- 未用真实游戏日志做端到端演示（本版只有单测证据）。
