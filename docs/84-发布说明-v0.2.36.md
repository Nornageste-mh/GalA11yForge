# 0.2.36 发布说明：GUI 里可以指定「分析程序」了

发布日期：2026-11-16
版本：0.2.36.0
类型：小版本（GUI 高级选项补全）
测试基线：678 通过 / 0 失败 / 0 跳过

## 1. 这版解决什么问题

0.2.35 在命令行上支持了“指定要分析的 exe”，但读屏用户大多用 GUI。
本版把这个能力接到图形界面：勾选「高级分析」后，多一个「分析程序」输入框。

## 2. 改动

- `src/Forge.Gui.Core/ForgeRequest.cs`：
  - 新增 `GhidraExecutablePath`；仅 `analyze` 命令追加
    `--option ghidra.executablePath=<路径>`（其它命令忽略，避免 CLI 报未知参数）。
- `src/Forge.Gui.Core/GuiStateMachine.cs`：
  - `GuiInputs` 新增 `GhidraExecutablePath`，`Create(...)` 末尾加可选参数；
  - 就绪提示在勾选高级分析且填了路径时追加「将分析你指定的程序：xxx.exe。」
- `src/Forge.Gui/MainForm.cs`：
  - 新增 `_ghidraExeBox`；输入区第 8 行「分析程序(&8)」，带「浏览…」选 *.exe；
  - 输入区高度 268F → 300F（8 行完整可见）；无障碍说明从“四个路径”改为“五个路径 + 分析程序”。
- `src/Forge.Gui/MainForm.Commands.cs`：`SnapshotInputs()` 带上 `_ghidraExeBox.Text`，`ForgeRequest` 传 `GhidraExecutablePath`。
- `src/Forge.Gui.Core/ForgeShortcuts.cs`：输入助记符扩到 Alt+1..8。
- 测试：`ArgumentBuilderTests` 新增 2 条（带路径时生成 `--option…`；非 analyze 忽略）；
  `ShortcutTests` 数量 7→8。Gui 154 通过。
