# 0.2.19.0 发布说明：IL2CPP 离线包随包 + 安装自动发现

- 日期：2026-11-15
- 发布目录：`releases/v0.2.19/`
- 测试基线：645 通过 / 0 失败 / 0 跳过（Core 94、Verify 64、Detection 30、Generators 59、Ren'Py 37、UnityMono 31、Build 79、Gui 141、Il2Cpp 55、Ghidra 55）

## 1. 这一版解决什么

上一版（0.2.18）发布包只带 Unity Mono 用的 BepInEx 5。用 IL2CPP 游戏时，`forge install` 必须手动传
`--bepinex BepInEx_win_x64_6.0.0-be.788.zip`，否则会报：

```
E_DEPENDENCY_MISSING 找不到 BepInEx 6.0.0-be.788 离线包
```

这不是用户该操的心。0.2.19 把 BepInEx 6 也随包，并让 install 自动发现它。

## 2. 改动

### 2.1 随包 BepInEx 6 离线包

- 新增 `tools/bepinex6/`：官方原样 `BepInEx_win_x64_6.0.0-be.788.zip`（34,336,405 B）+ `LICENSE-LGPL-2.1.txt` + `NOTICE-BepInEx6.txt`（版本/来源/SHA-256 说明）。
- `tools/release.ps1` 把 `tools\bepinex6\*` 复制到 `app\bepinex6\`，并把该 zip 的 SHA-256 写进 `SHA256SUMS.txt`。
- 只发官方原样包，不修改、不重分发修改版；包内哈希与 `BepInEx6Package.PinnedSha256` 一致
  （`F4CC496BD098A0DF4164B81E3737297707F13A47C2478DBA2F60EEFAB784817A`）。

### 2.2 IL2CPP 安装自动发现

- `BepInEx6Locator` 增加多搜索根重载：显式 `--bepinex` → 环境变量 `GALA11Y_BEPINEX6` →
  各搜索根（工作区、`AppContext.BaseDirectory`、`Environment.ProcessPath` 目录）。
- `PipelineCommands` 的 IL2CPP 分支调用 `ResolveBepInEx6Package`：没给 `--bepinex` 时按上述根
  自动找固定版本 zip；找不到仍返回带官方下载地址的诚实错误（不静默装未知版本）。
- 排序规则补 `bepinex6` 目录名优先；固定版本 be.788 永远排在其他 6.x zip 前面，保证哈希校验能过。

### 2.3 doctor 增补

- `forge doctor` 新增可选检查 `bepinex6-bundle`：找到 BepInEx 6 包时显示路径，找不到不算失败，只提示放哪。

## 3. 真机验证（[实测]）

1. 发布版 `forge doctor --json`：`bepinex-bundle` 与 `bepinex6-bundle` 均 passed=true、optional=true，detail 指向
   `releases\v0.2.19\app\bepinex*\...zip`。

   `forge install --game D:\Steam\steamapps\common\manosaba_game --workspace _il2cpp-b6-e2e --json`

   （未启动原版游戏、基线外运行期文件不判篡改）；游戏目录与插件目录恢复原状（仅保留用户原有
   `manosaba_a11y` 与 BepInEx 目录）。
