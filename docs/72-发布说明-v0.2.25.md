# 发布说明 v0.2.25.0（2026-11-15）

- 版本：`0.2.25.0`
- 发布目录：`releases/v0.2.25/`
- 上一版：0.2.24.0（Ren'Py 旧补丁冲突 hotfix）

## 1. 本版做了什么

### 1.1 安装闸门：错误详情列出旧补丁目录

0.2.24 起，游戏里已有旧无障碍覆盖层（`game/a11y_*`）时安装会被拒绝；
0.2.25 让错误详情直接给出“检测到哪几个目录”，并提示两种出路（卸载旧补丁，或 `--force` 叠加）。

- 代码：`src/Forge.Build/OverlayDeployer.cs`（`EnumerateOverlayDirectories` + 错误 details）
- 测试：`tests/Forge.Build.Tests/OverlayDeployerTests.cs::Plan_RefusesConflictOverlayWithoutForce_AndAllowsWithForce`
- 效果：`E_ENGINE_UNSUPPORTED` 的 `details.legacyOverlayDirectories = "game/a11y_game, game/a11y_platform"`。

### 1.2 Ren'Py 确认框：真机取证完成（A6）

在《永恒与星辰与日常》（Ren'Py 8.6）副本上用 0.2.24 发布版安装覆盖层，走：

> 开始游戏 → 对白 → quick menu「SYSTEM」→ 右下「标题 TITLE」→ 确认框

`a11y_speech.log` 出现：

```
[A11y屏幕] +460.303s 确认：Are you sure you want to return to the main menu? This will lose unsaved progress.
[A11y屏幕] +460.304s backend=NVDA 确认：…
```

回滚：删除 9 / 还原 0 / 清理目录 1 / 哈希不一致 0，overall=pass_with_skips（10 检查，0 失败，2 项未验证）。

证据目录：`research/66-renpy-confirm-screen/`
（日志、四张截图、回滚报告、可复现步骤与坐标）。

**已知缺口**（下一版改进）：

1. 界面是中文、播报是英文原文——取的是屏幕 source text，不是渲染后的翻译文本。
2. 确认框的「确认/取消」按钮名没有单独作为选项播报。
3. 该游戏的 SYSTEM 是设置屏而非经典游戏菜单；换游戏时菜单结构不同，产品只负责朗读、不负责自动点。
