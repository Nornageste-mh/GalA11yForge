# 0.2.73 发布说明：Ren'Py 通道计数口径修正

- 日期：2026-11-17
- 版本：0.2.73.0
- 上一版：0.2.72.0（语音指标给真数字）

## 1. 一句话

0.2.72 真机数据里出现「有效 6 行、Ren'Py 通道 8 行」这种自相矛盾的数；现在 `speechRenpyLines` 只统计**计入有效行**的 Ren'Py 通道行，且带 `backend=` 的重复行按回声处理。

## 2. 根因

- `RenpyBackendRx` 分支匹配到的行（带 `backend=SAPI` 的播报）没有标记为 Ren'Py 通道，导致带 backend 的行被算成“有效但不是 Ren'Py”；
- `renpyLines++` 原先在“参与统计”阶段自增，先于回声/占位过滤，所以会出现通道数 > 有效行数。

## 3. 改了什么

`src/Forge.Verify/SpeechLogInspector.cs`：

- `RenpyBackendRx` 命中时也置 `isRenpy = true`；
- `renpyLines++` 移到 `valid++` 之后（只统计有效行）；
- 测试 `Counts_renpy_overlay_channel_lines` 期望改为 2（带 backend 的重复行算回声）。

## 4. 验证

同一份 Ren'Py 归档日志（install → verify --speech-log → rollback）：

```
有效 6 行、去重 6 行、Ren'Py 通道 6 行、回声 2 行
```

（0.2.72：有效 6、Ren'Py 8、回声 2 —— 通道数 > 有效行，自相矛盾）

- 证据：`research/125-speech-metrics/verify-renpy-fix.json`
- 全量测试：**737 通过 0 失败**
