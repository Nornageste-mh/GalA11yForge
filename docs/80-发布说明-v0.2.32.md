# GalA11y Forge 0.2.32 发布说明

- 版本：`0.2.32.0`
- 日期：2026-11-16
- 发布目录：`releases/v0.2.32/`
- 上一版：`0.2.31.0`（GUI「分析报告」入口）

## 1. 本版做了什么

把「报告里的阻断待办」做成**结构化、可直接播报**的数据，而不是只躺在 `human-todos.md` 文件里：

1. CLI `report --json` 的 `data` 新增 `blockingTodos`：阻断待办最多 5 条，每条形如 `M-A01 该引擎没有内置适配器，不能自动生成可安装补丁`（只含编号 + 标题，不含台词）。
2. GUI 数据播报补中文标签：`markdownPath=报告文件`、`jsonPath=报告数据`、`humanTodosPath=人工待办文件`、`humanTodoCount=人工待办数`、`blockingCount=阻断项数`、`blockingTodos=阻断项`、`outputDirectory=输出目录`。
3. 结果区因此会直接出现：「阻断项数：1」「阻断项：M-A01 ……」，读屏用户不用手动打开 md 文件。

## 2. 为什么

目标⑤要求“能处理未知程序、可导出分析报告”。0.2.31 打通了 GUI 入口，但报告的关键结论（阻断待办）对读屏用户仍是“文件里的字”——要手动找、手动读。0.2.32 把它变成结果区就能听到的一句话。

## 3. 改动清单
