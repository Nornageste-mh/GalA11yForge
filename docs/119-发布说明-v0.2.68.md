# GalA11y Forge 0.2.68.0 发布说明

## 一句话
安装结果现在会说清楚「这个补丁有几个钩子、有没有兜底轮询」——不再让人以为装完就全自动读剧情。

## 为什么做
32 子代理体检（research/122）发现：8 份真机日志都是「6 个钩子挂载、0 命中、兜底 21–245 句」，但 install/verify 都没明示；用户看到“安装完成”以为钩子在工作。

## 改了什么
- \InstallNotice.Compose\ 新增参数 \hookCount\、\hasWatcherFallback\，结果文案追加：「本补丁有 N 个钩子；另外「文本兜底轮询」也开着…」；
- \orge install\ 从工作区缓存的 plan.json 数钩子数，并按引擎判断是否有兜底轮询（unity_mono 才有）；
- JSON 增 \hookCount\、\watcherFallback\ 两个字段；
- 更新两条既有测试 + 新增 1 条断言（有钩子/有兜底时文案与字段都对）。
