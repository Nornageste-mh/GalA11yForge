# 0.2.74 发布说明：给真台词入口留一个保底名额

- 日期：2026-11-17
- 版本：0.2.74.0
- 上一版：0.2.73.0（语音通道计数口径）

## 1. 一句话

计划里 6 个钩子名额可能被高分菜单/对话框占满、把真正的台词入口挤出去；现在选完名额后会检查「有没有 Dialogue 类候选」，没有就用最高分台词候选换掉最后一个。

## 2. 问题来源

32 个子代理体检（research/141）里，《Mystery Lover 2.5》：

- 真台词入口 `Utage.AdvMessageWindow::PageTextChange` 约 85 分；
- `Utage.SystemUiDialog*::Open` 这类系统对话框 95 分以上；
- `MaxHookPoints = 6` 硬截断 → 台词入口被挤出，装完只有弹对话框才念。

## 3. 改了什么

`src/Forge.Adapters.UnityMono/Internal/UnityMonoPlanner.cs`：

- 建 views 时记录分析阶段标为 `TextCandidateKind.Dialogue` 的候选 id；
- 选满名额（或不足名额）后，若 `selected` 里一个 Dialogue 都没有，取 `views` 中最高分的 Dialogue 候选；名额满了就替换最后一个，没满就追加。

不改评分、不改名额上限，只做一次保底替换。

## 4. 测试

新增 `tests/Forge.Adapters.UnityMono.Tests/PlanTests.cs::Plan_ReservesSlotForDialogueCandidate_WhenMenusFillTheQuota`：

- 6 个 100 分菜单候选 + 1 个 60 分台词候选；
- 断言计划仍是 6 个补丁点，且包含 `Game.DialogueUI:ShowText`。

全量：**737 通过 0 失败**（UnityMono 44）。
