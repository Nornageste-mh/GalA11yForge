# 发布说明：GalA11y Forge v0.2.13.0（2026-11-15）

状态：**已发布**，目录 `releases/v0.2.13/`。

## 1. 本版一句话

修掉 0.2.12 在 manosaba 复验时暴露的 bug：**形参无名但类型是 string 的方法被误当“字段兜底”入口**，
生成的补丁注定编译不过；现在这类目标只进人工待办，字段兜底只给真正“没有 string 形参”的入口。

## 2. 改动

### 2.1 计划器（`Il2CppPlanner`）

字段兜底分支原先只判断 `!target.CanGenerateHook`，而 `CanGenerateHook=false` 有两种原因：
① 没有 string 形参（真字段入口）；② 有 string 形参但形参没名字（如 `set_messageText(System.String|)`）。
0.2.12 把 ② 也当字段补丁，生成强类型 `__instance` 补丁后编译失败（CS0012 UIBehaviour 缺引用）。
0.2.13 改为只有 `fieldOnly`（`!HasStringParameter && CanGenerateFieldFallback && HasSupportedField`）
才走字段分支，其余 `!CanGenerateHook` 目标写人工待办。

### 2.2 生成器（`Il2CppGenerator`）

字段补丁的 `Postfix` 是强类型 `global::<类型> __instance`；实例类型常继承 `UIBehaviour`（Naninovel ChatMessage），
即使读取字段本身不是 UGUI 组件，也需要 `UnityEngine.UI` 引用。现在字段补丁无条件置 `needsUnityUi=true`，
模板会给 `UnityEngine.UI`/`UnityEngine.UIModule` 加带 `Condition="Exists(...)"` 的引用（缺了不报错）。

### 2.3 测试

- 新增 `Plan_UnnamedStringParameter_DoesNotBecomeFieldHook`（断言不生成补丁点、有人工待办、无字段读取器产物）。
- 字段补丁测试增加 `UnityEngine.UI` 引用断言。
- IL2CPP 测试 52 通过；全量 638 通过 / 0 失败。
