# 0.2.8.0 发布说明

发布日期：2026-11-15
版本纪律：按用户 2026-11-14 邮件要求，统一在 0.2.x 上叠加。

## 1. 本版做了什么

### 1.1 字段补读等待时间可配置

0.2.7 修掉了「Unity Mono 首句漏读」：钩子触发时台词还没写进字段，读不到就登记一次延迟复查，最多等 4 秒再补读。
这版把这个 4 秒上限做成配置项：

- 配置位置：插件配置 `[朗读] 字段补读最长等待秒`，默认 4.0。
- 取 0：关闭补读（不登记、不复查）——适合「怕念旧句/怕和翻页撞车」的游戏。
- 取值上限 15 秒；负数按 0 处理。
- 实现：`SpeechGate.ConfigureFieldRecheck` 在插件启动时接收配置；`ScheduleFieldRecheck` 与 `Update` 都先看这个值。

### 1.2 真机验证（配置 0 路径）

GalMaster（Unity Mono，BepInEx 5）：把配置设成 0 后启动、进对话、推进两次：

- 日志里「已登记延迟复查」「延迟复查补读」出现 0 次；
- 首句只进重读缓冲（`[Speech:note]`），不主动朗读；
- 第二句起正常 `[Speech]`；
- 回滚 `overall=pass_with_skips`，删 23、还原 0、哈希不一致 0。

证据：`_galmaster-v026e/evidence/LogOutput-config0.log`、`summary-0.2.8-config0.md`。
