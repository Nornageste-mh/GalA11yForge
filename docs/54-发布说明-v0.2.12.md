# 发布说明：GalA11y Forge v0.2.12.0（2026-11-15）

状态：**已发布**，目录 `releases/v0.2.12/`。

## 1. 本版一句话

IL2CPP 游戏里那些“把台词放在实例字段、方法本身没有 string 参数”的文本入口，现在能被自动识别并生成
「按原生字段读取」的补丁；《The NOexistenceN of Lilith》真机已读到台词。

## 2. 改动

### 2.1 IL2CPP 字段兜底（主功能）

- 分析（`Il2CppAnalyzer`）：
  - 记录类型上的文本字段（`类型文本字段：字段:类型/…（实例方法）`），作为跨阶段契约；
  - 对“无 string 形参、但类型有文本字段、方法名像展示动词、类型像 UI/文本宿主”的候选加权：
    展示动词（show/display/print/…）补到 52 分，其余补到 45 分，证据行写 `字段兜底加权：…`；
  - 字段名黑名单：`_diag/_debug/_log/status/path/key/hash/url/version/prefab` 等不进证据。
- 计划（`Il2CppPlanner`）：仅对「没有 string 形参」的字段候选放行（避免 DOTween `set_xxx(string)` 这类误入），
  生成 Description 带 `类型文本字段：…` 的补丁点。
- 生成（`Il2CppGenerator` + `Il2CppTemplates`）：
  - 新增 `A11y/A11yFieldReader.cs`：`il2cpp_object_get_class` → `il2cpp_class_get_field_from_name`（沿父类链，
    兼容 `<name>k__BackingField`）→ `il2cpp_field_get_value_object`；string 用 `Il2CppStringToManaged`，
    TMP/UGUI 组件用 interop 包装后读 `.text`；字段指针缓存、异常吞掉并记日志；日志前缀 `[Speech:fields]`。
  - 新增字段版 Harmony Hook：`Postfix(global::<类型> __instance)`，读字段后交 `A11yRuntime`。
  - metadata 新增 `field_fallback_hooks`；csproj 按字段类型自动加 Unity.TextMeshPro/UnityEngine.UI 引用。
- 修复：`Il2CppGenerationBridge` 原先把「字段兜底钩子」误判为不可生成（E_PARTIAL），改为按生成结果 `hook_count` 判断；
  `FieldSpec` 改为命名空间级 `A11y.FieldSpec`（原先写成嵌套类型导致 CS0426）。

## 3. 真机证据

游戏：《The NOexistenceN of Lilith》（IL2CPP，已装 BepInEx 6.0.0-be.788 + interop）。

- 分析：40+ 候选；`DialogueBubbleUI::ShowNode` 52 分、`ShowOptions` 52 分等进入计划。
- 计划：6 个钩子（ShowNode、ShowOptions、GiftCellView×2、LilithFolderView×2），13 个生成物。
- 构建：`the-noexistencen-of-lilith.il2cpp.a11y.dll` 18,944 B。
- 运行（手工放入插件目录，非 `forge install`）：`[Speech:fields]` 16 条；`ShowNode` → `_dialogueText`（4 字，
  即屏幕上的「周末快乐」）；`_diag|not started` 0 条；升级后的噪声日志从 1,010 条降到 16 条。
- 局限：该机缺少 Tolk，运行期降级为日志输出，**未验证真人听到声音**；UI 文本仍可能被读（`GiftCellView::SetRootVisible` 读出饰品名）。
- 证据：`research/50-il2cpp-field-fallback/evidence/runtime-fieldhook-LogOutput.log`（过滤前 255,179 B）、
  `runtime-fieldhook-filtered-LogOutput.log`（过滤后 8,251 B）。
