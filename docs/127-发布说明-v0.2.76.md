# 0.2.76 发布说明：日语游戏 + 本机没日语语音时，安装完会提醒你

- 日期：2026-11-17
- 版本：0.2.76.0
- 上一版：0.2.75.0（安装结果给日志路径与自检命令）

## 1. 一句话

分析阶段若看到 `language=ja` 一类日语文本标记，而本机 `doctor` 又查不到日语语音，安装完成时会多一行提醒，不阻断安装。

## 2. 改了什么

- 新增 `src/Forge.Cli/JapaneseVoiceNotice.cs`：`ShouldWarn(hasJapaneseVoice, evidenceLines)` + 统一文案（含“Windows 设置 → 时间和语言 → 语音里装日语语音”的指引）。
- `src/Forge.Cli/PipelineCommands.cs`：install 成功后读取缓存的 `analysis.json`，扫描候选证据里的 `language=ja`/`language:ja`/`language=japanese`；命中且本机无日语语音时，stderr 打 `[注意] …`，JSON `data.japaneseVoiceMissing = true`。

## 3. 验证

- 新增 `tests/Forge.Core.Tests/CliTests.cs::Japanese_voice_warning_only_fires_for_japanese_text_without_voice`（ja 且无语音 → true；有语音 → false；sc → false；空证据 → false）。
- 全量 **740 通过 0 失败**（Core 119）。
