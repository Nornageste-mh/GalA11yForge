# GalA11y Forge 0.2.64.0 发布说明

## 一句话
计划阶段开始做「死代码弱判定」：本程序集内没有调用者的钩子排到最后，并新增 R-107 提醒——避免把补丁打在不运行的旧代码上。

## 为什么做
32 子代理体检（research/141）发现《妹控计划》6 个钩子全打在 DialogueSceneManager 等不运行的旧代码上，真正跑的是 ShiMeng.DialogueV2；当时产品没有任何提示，用户会以为补丁可用。

## 改了什么
- \src/Forge.Adapters.UnityMono/Internal/UnityMonoPlanner.cs\：
  - 新增 \IsLikelyDeadCode(view)\：从候选证据行「程序集内调用者 N 个」读调用者数，N=0 视为可能死代码；
  - \CompareViews\ 在同等优先级/分数下把死代码候选排后；
  - \BuildRisks\ 新增 **R-107（中风险）**：「计划里有 N 个钩子在本程序集内没有调用者（可能是未运行的旧代码/死代码），装好后可能一句都不读」，列出前 3 个目标。
- 新增测试 \	ests/Forge.Adapters.UnityMono.Tests/DeadCodePlanTests.cs\：死代码候选 100 分 vs 有调用者候选 90 分 → 排序取活的、且出现 R-107。
