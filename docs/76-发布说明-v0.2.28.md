- 版本：**0.2.28.0**

- 定位：小版本（未知引擎的“分析→报告”链路补全 + 文案纠错），无破坏性变更。

## 1. 本版改动

### 1.1 没有内置适配器的引擎也能导出分析报告

以前：`forge report` 会先跑 analyze + plan；没有适配器的引擎（如 KiriKiri）在这里直接报 `E_NOT_IMPLEMENTED`，即使你刚用 `analyze --advanced` 跑完 Ghidra 也导不出报告。

现在：
- `report` 允许在没有适配器时解析，并**优先复用工作区里 `01-analyze/analysis.json`**——不重跑 Ghidra，秒出报告。
- 方案部分生成“诚实骨架”：`route=D 不支持`，并写入阻断人工待办“该引擎没有内置适配器，不能自动生成可安装补丁”，同时把分析里的未覆盖/人工待办搬进 `human-todos.md`。
- `report` 仍支持有适配器的引擎：有缓存用缓存，无缓存照旧现场 analyze+plan。

### 1.2 未知引擎提示文案纠错

旧文案是“先支持 Ren'Py 路线；Unity Mono 适配器正在集成”（0.1 时期的说法，已过时）。现改为：

> 该引擎暂无内置适配器：可先用 `analyze --advanced` 跑 Ghidra 静态分析，再用 `report` 导出报告；真正可玩仍需运行时方案或人工分析。

### 1.3 单测

新增 `tests/Forge.Core.Tests/AdapterlessReportTests.cs`：构造只有 `data.xp3`+`game.exe` 的假目录 + 手写 `01-analyze/analysis.json`，跑 `report --json`，断言 exit 0、route=Unsupported、`report.md`/`human-todos.md` 写出且含“阻断”“没有内置适配器”。
