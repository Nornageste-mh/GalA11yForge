## 2. 发布门槛（0.2.4.0）

1. `dotnet test src/GalA11yForge.sln -c Release` 全绿（当前 **612** = 607 + BepInEx 定位器 5）。
2. `ForgeInfo.cs` 版本串与发布目录一致；golden 重生成。
3. 真机证据：KKZ 闭环（若产品化）或"不产品化"的结论 + 证据；GUI 用户回执（若拿到）。
4. `tools/release.ps1 -Version 0.2.4.0` 发布物 + `SHA256SUMS.txt`（含 `app/bepinex/BepInEx_win_x64_5.4.23.5.zip`）+ 发布目录 README。
