# GalA11y Forge 0.2.62.0 发布说明

## 一句话
IL2CPP 游戏安装完成后，如果没指定 \--speech-runtime\，安装结果会直接说明「插件只写日志、不朗读」以及怎么开声音。

## 为什么做
32 子代理体检（research/110）在《The NOexistenceN of you AND me》上发现：IL2CPP 的默认安装不带 Tolk 语音运行时，插件降级成只写日志，但 CLI 仍报「安装完成」——用户以为补丁能读，实际没声音。

## 改了什么
- 新增 \src/Forge.Cli/InstallNotice.cs\：\Compose(isIl2Cpp, speechRuntimePath, data)\ 生成安装结果文案；IL2CPP 且没给 \--speech-runtime\ 时追加提示，并写入 JSON 字段 \speechRuntimeMissing=true\。
- \RunInstallAsync\ 改为调用该辅助方法（成功消息不再硬编码）。
- 新增测试 \InstallNotice_ForIl2CppWithoutSpeechRuntime_TellsUserItIsLogOnly\、\InstallNotice_WithSpeechRuntimeOrMono_StaysPlain\。

## 验证
- Core 测试 108 通过（+2）；全量 **722 通过 0 失败**。
- 未在真实 IL2CPP 游戏上重跑安装（需要 BepInEx 6 + 游戏副本，磁盘只剩约 3GB）。
