# 0.2.41 发布说明：无适配器引擎，GUI「一键」不再白失败

- 发布目录：`releases/v0.2.41/`
- 日期：2026-11-16
- 测试：**697 通过 / 0 失败**

## 1. 这版解决什么问题

对「已识别、但没有内置适配器」的引擎（例如 KiriKiri），旧版界面点「一键」会在“分析”这一步
失败；虽然命令行提示可以用 `analyze --advanced` 和 `report`，但界面里的用户看不到结果，
也没有报告文件。

这版把这条“失败后的正确下一步”接进了一键流程：

1. 分析报 `E_NOT_IMPLEMENTED`、且说明里确实是“没有适配器”时，界面自动改用 `--advanced`
   （Ghidra 高级静态分析）重跑；
2. 分析完成后自动导出 `report`（Markdown/JSON + 人工待办清单）；
3. 结果区显示“为什么改道、报告在哪、还需要人工做什么”，读屏会念出来。

## 2. 改了什么（技术）

- 新增 `src/Forge.Gui.Core/AdapterlessFlow.cs`
  - `IsAdapterlessAnalyzeFailure(...)`：只认 `E_NOT_IMPLEMENTED` 且消息/建议符合“无适配器”的失败；
  - `TryGetEngineFamily(...)`、`Explain(...)`：给读屏的一句中文说明。
- `src/Forge.Gui/MainForm.Commands.cs`
  - `ExecuteOneAsync(..., bool? advancedOverride = null)`；
  - `RunSequenceAsync` 新增 `adapterlessStop` 分支：Analyze 命中后自动重试 `--advanced`，
    自动跑 `report`，随后停止本序列，避免继续撞 `generate` 的第二个错误。
- 测试：`AdapterlessFlowTests` 5 条；Gui 166 通过。
