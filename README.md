# GalA11y Forge（无障碍补丁工坊）

把「一个 Galgame 的安装目录」变成「能读屏玩」：
自动识别引擎 → 分析文本管线 → 规划补丁点 → 生成补丁工程 → 构建 → 安装 → 自检 → 回滚。
机器搞不定的部分明确产出「人工待办」，不假装成功。

## 快速开始

见 `docs/18-使用指南-v0.md`（人话版）或 `releases/v0.2.4/README.md`（发布包内）。

最短路径：

```powershell
$forge = '.\releases\v0.2.4\app\forge.exe'
$game  = 'D:\Steam\steamapps\common\五天一夜所在目录'
$ws    = "$env:LOCALAPPDATA\GalA11yForge"
& $forge detect  --game $game
& $forge analyze --game $game --workspace $ws
& $forge plan    --game $game --workspace $ws
& $forge generate --game $game --workspace $ws
& $forge build   --game $game --workspace $ws --bepinex 'D:\path\to\BepInEx_win_x64_5.4.23.5.zip'
& $forge install --game $game --workspace $ws --bepinex 'D:\path\to\BepInEx_win_x64_5.4.23.5.zip'
# 启动游戏、听声音，然后：
& $forge verify  --game $game --workspace $ws
# 卸载：
& $forge verify  --game $game --workspace $ws --rollback --force
```
