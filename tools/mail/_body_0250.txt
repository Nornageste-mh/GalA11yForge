0.2.5.0 已发布（releases/v0.2.5/，618 测试全绿）。这一版主要是补上一个“泛化缺口”：

【新功能：字段兜底朗读】
- 有些游戏把台词写在实例字段里，钩子方法本身没有字符串参数——之前的生成物只能“计调用次数”，不会朗读。
- 现在生成器会按分析证据反射读这些实例文本字段，走 SpeechGate → Repeat → 读屏器。
- 在第二款 Unity Mono 游戏 GalMaster（9.8GB，未装过补丁）真机跑到剧情，日志出现 4 句：
  “晓夜，Xiao Ye，老哥，我大概还有半个小时就到你住的地方咯？”
  “晓夜，Xiao Ye，已经回去了吗？”
  “黎铭，Li Ming，我还在商业街，干脆你顺路过来这边，等下一起回去吧？”
  “正式开始独居的第二周，晓夜提议要来我住的地方看看。”
  回滚后游戏目录 0 差异，verify 显示 not_installed（已卸载，不退化成假通过）。

【顺手修的 4 个产品问题】
1. install 自动从随包 app\bepinex\ 找 BepInEx，不再要求手动指定；参数名文案改正。
2. plan 的人工待办/风险改成按本次实际入口生成，不再硬编码别的游戏的方法名与无来源数字。
3. verify 在“没装/已卸载”时输出 not_installed（退出 0，并明说“不等于通过”）；每次自检额外保留带时间戳报告，不覆盖。
4. “无文本来源”警告的判定扩展：有实例文本字段也算可朗读来源。
